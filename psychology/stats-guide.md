# 心理学统计方法操作指南

> 本科毕业论文常用统计方法的具体操作和结果解读。以SPSS为主，R为辅。

## 一、描述性统计

### 操作步骤（SPSS）
1. 分析 → 描述统计 → 描述
2. 把需要描述的变量选入"变量"
3. 选项：勾选均值、标准差、最小值、最大值
4. 确定

### 结果解读
- 均值（M）：集中趋势
- 标准差（SD）：离散程度
- 偏度绝对值<1为近似正态，峰度绝对值<1为近似正态

### 论文表述
"本研究共回收有效问卷X份，其中男生X人（X%），女生X人（X%）。各变量均值和标准差见表1。"

---

## 二、信度检验

### Cronbach's α系数
**操作步骤（SPSS）：**
1. 分析 → 刻度 → 可靠性分析
2. 把同一个量表的所有题目选入"项目"
3. 模型选"Alpha"
4. 统计：勾选"项之间的相关性"（可选）
5. 确定

**判断标准：**
- α > .90：优秀
- α = .80-.90：好
- α = .70-.80：可接受
- α = .60-.70：勉强接受，需说明
- α < .60：不可接受，检查题目或删题

**删题判断：**
- 看"删除项后的Cronbach's α值"，如果删某题后α明显升高，考虑删除
- 删题要在论文中说明理由

### 论文表述
"本研究中，XX量表的Cronbach's α系数为.XX，表明该量表具有良好的内部一致性信度。"

## 三、效度检验

### 内容效度
- 引用原量表的效度证据
- 说明使用的是经过国内验证的中文版

### 结构效度（验证性因子分析CFA）
- 本科论文可用AMOS、Mplus或R的lavaan包
- 报告指标：χ²/df < 3，RMSEA < .08，CFI > .90，TLI > .90，SRMR < .08
- 如果不做CFA，可以用探索性因子分析（EFA）代替

### 探索性因子分析（EFA）操作（SPSS）
1. 分析 → 降维 → 因子分析
2. 把量表题目选入"变量"
3. 描述：勾选"KMO和Bartlett球形检验"
4. 提取：方法选"主成分分析"，因子数按理论维度
5. 旋转：选"最大方差法"
6. 选项：勾选"按大小排序""取消小系数"（绝对值>.40）
7. 确定

**判断标准：**
- KMO > .70适合做因子分析
- Bartlett球形检验显著（p < .05）
- 因子载荷 > .40为可接受，>.50为好

## 四、共同方法偏差检验

### Harman单因子检验
**操作步骤（SPSS）：**
1. 把所有量表的所有题目放在一起做因子分析
2. 分析 → 降维 → 因子分析
3. 不指定因子数，让系统自动提取
4. 看第一个因子解释的方差百分比

**判断标准：**
- 第一个因子解释率 < 40%：共同方法偏差不严重
- 第一个因子解释率 > 40%：可能存在严重共同方法偏差，需在讨论中说明局限

**论文表述：**
"采用Harman单因子检验共同方法偏差。结果显示，第一个因子解释了XX%的方差，小于40%的临界值，表明本研究不存在严重的共同方法偏差。"

## 五、相关分析

### Pearson相关
**操作步骤（SPSS）：**
1. 分析 → 相关 → 双变量
2. 把要分析的变量选入"变量"
3. 相关系数选"Pearson"
4. 显著性检验选"双侧检验"
5. 勾选"标记显著性相关"
6. 确定

**结果解读：**
- r = .10-.29：小相关
- r = .30-.49：中等相关
- r = .50-1.0：大相关
- p < .05为显著，p < .01为非常显著

**论文表述：**
"相关分析结果显示，XX与YY呈显著正相关（r = .XX, p < .01），与ZZ呈显著负相关（r = -.XX, p < .05）。"

## 六、中介效应检验（PROCESS宏）

### 安装PROCESS
1. 下载PROCESS宏（hayesprocess.com，免费）
2. SPSS → 实用程序 → 安装自定义对话框
3. 选择下载的process.spd文件
4. 安装后在"分析→回归"里能看到PROCESS

### 简单中介（模型4）
**操作步骤：**
1. 分析 → 回归 → PROCESS
2. 自变量（X）放入"自变量"
3. 因变量（Y）放入"因变量"
4. 中介变量（M）放入"中介变量"
5. Model number填4
6. Bootstrap samples填5000
7. Confidence level填95
8. 确定

**结果解读：**
- 总效应（c路径）：X对Y的总效应
- 直接效应（c'路径）：控制M后X对Y的效应
- 间接效应（a*b）：Bootstrap置信区间不包含0则显著
- 完全中介：直接效应不显著，间接效应显著
- 部分中介：直接效应和间接效应都显著

### 链式中介（模型6）
**操作步骤：**
- 同上，Model number填6
- 中介变量按链式顺序放入（M1在前，M2在后）

**结果解读：**
- 总间接效应：Bootstrap CI不包含0则显著
- 特定间接路径：
  - X→M1→Y（路径1）
  - X→M1→M2→Y（路径2，链式）
  - X→M2→Y（路径3）
- 每条路径的Bootstrap CI不包含0则该路径显著

**论文表述：**
"采用Hayes的PROCESS宏（模型6）进行链式中介效应检验，Bootstrap抽样5000次。结果显示，XX对YY的直接效应显著（β = .XX, p < .05）；XX→M1→M2→YY的链式中介效应显著（间接效应 = .XX, 95% CI = [.XX, .XX]，不包含0）。"

## 七、调节效应检验（PROCESS模型1）

**操作步骤：**
1. 分析 → 回归 → PROCESS
2. X放入自变量，Y放入因变量
3. 调节变量W放入"调节变量"
4. Model number填1
5. 勾选"条件效应"（Johnson-Neyman法）
6. Bootstrap 5000次
7. 确定

**结果解读：**
- 交互项（X×W）显著则调节效应存在
- 看简单斜率：在W的均值±1个标准差时，X对Y的效应是否显著

---

## 八、有调节的中介（PROCESS模型7/14/15）

- 模型7：调节前半路径（X→M）
- 模型14：调节后半路径（M→Y）
- 模型15：同时调节前后路径
- 操作同上，选对应模型号

## 九、网络分析（补充分析，可选）

### 适用条件
- 样本量 > 250
- 想展示变量间的整体关系结构

### R语言操作
```r
# 安装包
install.packages(c("qgraph", "bootnet"))

# 加载
library(qgraph)
library(bootnet)

# 估计网络（EBICglasso）
network <- estimateNetwork(data, default = "EBICglasso")

# 画图
plot(network, layout = "spring")

# 中心性
centralityPlot(network)
```

### 结果解读
- 节点：变量或维度
- 边：偏相关系数，越粗越强，绿色正相关，红色负相关
- 中心性指标：强度（strength）、接近性（closeness）、中介性（betweenness）
- 强度最高的节点是核心节点

## 十、统计结果报告规范

### 表格
- 用三线表
- 表号+表题在表格上方
- 均值标准差写成 M ± SD
- 相关矩阵标注显著性（*p<.05, **p<.01）

### 图
- 图号+图题在图下方
- 坐标轴有标签和单位
- 分辨率至少300dpi
- 黑白为主，不用花哨颜色

### 数字
- 小数保留2-3位
- p值：p < .05, p < .01, p < .001（不写p = .000）
- β、r、t、F、χ²等统计量保留2位小数
