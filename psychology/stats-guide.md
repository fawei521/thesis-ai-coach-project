# 心理学统计方法操作指南

> 本科毕业论文常用统计方法的具体操作和结果解读。以SPSS为主，R为辅。

## 一、描述性统计

### 操作步骤（SPSS）
1. 分析 → 描述统计 → 描述
2. 把需要描述的变量选入"变量"
3. 选项：勾选均值、标准差、最小值、最大值
4. 确定

### 结果解读
- 均值（M）：集中趋势；标准差（SD）：离散程度
- **正态性看偏度（Skewness）与峰度（Kurtosis，SPSS 给的是超额峰度）**：
  - 社科问卷常用 Kline 判据：|偏度| < 3 且 |峰度| < 10，即视为不严重偏离正态，可做参数检验；更严格用 |偏度| < 2、|峰度| < 7
  - 偏度标准误 ≈ √(6/N)、峰度标准误 ≈ √(24/N)，偏度/标准误绝对值 > 1.96 表示显著偏态（大样本几乎都会显著，故主要看数值大小而非显著性）
  - 明显偏态时不必硬转正态：相关/回归对轻度偏态稳健，**中介与间接效应直接用 Bootstrap（本工具默认）**，不依赖正态假设
- 脚本 `auto_stats.py` 自动输出各量表总分的偏度/峰度与判读（SPSS 调整口径，经 scipy 黄金对照逐位一致），并在"数据名_统计结果.csv"生成**表2：均值M、标准差SD、相关矩阵（下三角，带显著性星号）、对角为 Cronbach's α**，即论文标准"表1 描述统计与相关分析"，可直接整理成三线表

### 论文表述
"本研究共回收有效问卷X份，其中男生X人（X%），女生X人（X%）。各变量均值和标准差见表1。"

## 二、信度检验

### Cronbach's α系数
**操作步骤（SPSS）：**
1. 分析 → 刻度 → 可靠性分析
2. 把同一个量表的所有题目选入"项目"
3. 模型选"Alpha"
4. 统计：勾选"项之间的相关性"（可选）
5. 确定

**判断标准：**
- α > .90：优秀
- α = .80-.90：好
- α = .70-.80：可接受
- α = .60-.70：勉强接受，需说明
- α < .60：不可接受，检查题目或删题

**题项分析（删题判断，SPSS 可靠性分析→"项删除后的标度/统计"）：**
- **CITC（校正项总相关，Corrected Item-Total Correlation）**：某题与"该量表其余题目总分"的相关。CITC ≥ .50 良好，.40–.50 可接受，**< .40（严格用 .35）说明该题与整体不同步，考虑删除或修改**。
- **删题后 α（Alpha if Item Deleted）**：删除该题后剩余题的 α。若删某题后 α 明显高于（如高 .02 以上）总 α，说明该题拉低了一致性，结合理论考虑删除。
- 两条同时异常的题优先排查；删题必须有理论/内容依据，不能只看数字，且删后要重算 α 与因子结构。

**脚本自动输出：** 跑 `auto_stats.py`（提供 `--scales`）会逐题打印 CITC 与删题后 α、自动标记异常题，并导出"数据名_题项分析.csv"（量表/题项/CITC/删题后α/总α/提示，UTF-8-SIG 可直接整理成信度三线表）。

### 论文表述
"本研究中，XX量表的Cronbach's α系数为.XX，各题CITC在.XX–.XX之间（均>.40），删题后α均未升高，表明该量表具有良好的内部一致性信度。"

## 三、效度检验

### 内容效度
- 引用原量表的效度证据
- 说明使用的是经过国内验证的中文版

### 结构效度（验证性因子分析CFA）
- 本科论文可用AMOS、Mplus或R的lavaan包
- 报告指标：χ²/df < 3，RMSEA < .08，CFI > .90，TLI > .90，SRMR < .08
- 如果不做CFA，可以用探索性因子分析（EFA）代替

### 探索性因子分析（EFA）

**什么时候必须做、什么时候不必做：**
- 自编量表、对成熟量表做了重大修订（删题/合并维度/换人群）→ 应做完整 EFA。
- 直接使用成熟量表且维度已被反复验证 → 报告 KMO、Bartlett、各题在所属维度上的载荷即可（脚本默认的"结构效度"单维第一主成分检查已够用），不必强行多因子 EFA。
- EFA 与 CFA 最好在**不同子样本**上做（把样本随机分两半，一半 EFA 一半 CFA）；本科论文样本有限时，做 EFA 并在讨论中说明局限也可接受。

**操作（SPSS）：**
1. 分析 → 降维 → 因子分析
2. 把量表题目选入"变量"
3. 描述：勾选"KMO和Bartlett球形检验"
4. 提取：方法选"主成分分析"；先让系统按特征值≥1提取，结合碎石图和理论维度确定因子数
5. 旋转：维度间理论上相互独立选"最大方差法Varimax"（正交）；认为维度彼此相关选"Promax"（斜交）
6. 选项：勾选"按大小排序""取消小系数"（绝对值填 .40）
7. 确定

**判断标准（心理学通行口径）：**
- 取样适当性 KMO：>.90 极佳，>.80 适合，>.70 可接受，>.60 勉强，<.60 不宜做因子分析。
- Bartlett 球形检验需显著（p < .05），即题目间相关足够、不是单位阵。
- 样本量：理想为题数的 10～20 倍且 N≥200；低于题数 5 倍时结果不稳，脚本会提示。
- 因子数：四种依据综合判断——①特征值≥1（Kaiser 准则，仅作起点，倾向高估）；②碎石图拐点；③**平行分析（Horn's Parallel Analysis）**：把真实特征值与大量随机数据的特征值（均值/95%分位）比较，真实值超过随机95%分位的连续成分数即建议因子数，是当代方法学最受推荐的判据（Glorfeld 1995 建议用95%分位更保守）；④理论维度。脚本一次给出前三项并把随机均值/95%线画进碎石图；几者不一致时，以平行分析＋理论为准，并在 JASP 固定该因子数复核，不能只看特征值≥1。
- 因子载荷：≥.40 可接受、≥.50 较理想；交叉载荷（在两个因子上都≥.40，且二者之差<.20）的题项考虑删除。
- 累计方差解释率：社会科学建议 ≥50%～60%。
- 正交旋转看"旋转成分矩阵"；斜交 Promax 报告"模式矩阵 Pattern Matrix"并报告因子间相关。

**论文里要报告的五块（APA 风格）：**
1. 提取与旋转方法及选择理由（如"主成分分析提取、最大方差法正交旋转，因理论上各维度相互独立"）；
2. KMO 值与 Bartlett 的 χ²、自由度、p；
3. 因子数确定依据（特征值≥1＋碎石图＋平行分析＋理论，并报告平行分析建议的因子数）；
4. 各因子特征值与累计方差解释率；
5. 旋转后载荷矩阵（题项×因子，含共同度），交叉载荷/删题情况。

**用本项目脚本一键做 EFA（快速预览/教学，正式结果仍建议 JASP/SPSS 复核）：**
```
# 对全部量表做完整EFA
python tools/auto_stats.py 数据.csv --scales scales.txt --efa
# 只对某几个自编量表做（空格或逗号分隔）
python tools/auto_stats.py 数据.csv --scales scales.txt --efa 我的新量表,修订量表
```
脚本会输出 KMO、Bartlett、全部特征值、按特征值≥1确定的因子数、**Horn 平行分析（默认500次随机模拟，给出随机特征值均值/95%分位与建议因子数，可用 `--pa-rep 次数` 调整或 `--pa-rep 0` 关闭）**、Varimax 旋转后载荷矩阵、共同度、交叉载荷与低载荷标记、累计方差解释率，并导出"数据名_因子分析.csv"（题项×因子载荷长表，便于整理成三线表）；**同时为每个量表导出"数据名_量表名_碎石图.png"**（300dpi，含 λ=1 参考线、平行分析随机均值/95%分位线与保留因子高亮，拐点一目了然，可直接插入论文）。菜单第 3 项在输入 scales.txt 后会询问是否做 EFA（默认含平行分析）。

**脚本做不到、需要 JASP/SPSS 的部分（要在论文中如实处理）：** 手动固定因子数、Promax 斜交旋转与因子相关矩阵、CFA 拟合指标。JASP 免费：Factor → Exploratory Factor Analysis 可固定因子数、做 Promax 斜交并查看碎石图，Factor → Confirmatory Factor Analysis 可做 CFA。

## 四、共同方法偏差检验

### Harman单因子检验
**操作步骤（SPSS）：**
1. 把所有量表的所有题目放在一起做因子分析
2. 分析 → 降维 → 因子分析
3. 不指定因子数，让系统自动提取
4. 看第一个因子解释的方差百分比

**判断标准：**
- 第一个因子解释率 < 40%：共同方法偏差不严重
- 第一个因子解释率 > 40%：可能存在严重共同方法偏差，需在讨论中说明局限

**论文表述：**
"采用Harman单因子检验共同方法偏差。结果显示，第一个因子解释了XX%的方差，小于40%的临界值，表明本研究不存在严重的共同方法偏差。"

## 五、相关分析

### Pearson相关
**操作步骤（SPSS）：**
1. 分析 → 相关 → 双变量
2. 把要分析的变量选入"变量"
3. 相关系数选"Pearson"
4. 显著性检验选"双侧检验"
5. 勾选"标记显著性相关"
6. 确定

**结果解读：**
- r = .10-.29：小相关
- r = .30-.49：中等相关
- r = .50-1.0：大相关
- p < .05为显著，p < .01为非常显著

**论文表述：**
"相关分析结果显示，XX与YY呈显著正相关（r = .XX, p < .01），与ZZ呈显著负相关（r = -.XX, p < .05）。"

### 人口学差异分析（独立样本t / 单因素ANOVA）
检验性别、是否独生子女等**二分类**变量在各量表上的差异用**独立样本 t 检验**；年级、生源地等**三类及以上**变量用**单因素方差分析（ANOVA）**。

**SPSS：** 分析 → 比较平均值 → 独立样本T检验（t）；单因素ANOVA（事后比较选 Bonferroni/LSD）。

**脚本自动完成：** `auto_stats.py --scales scales.txt` 自动识别人口学分组列（非量表题、2–4类编码或文本"男/女"），对每个量表总分：
- 2组：独立样本 t（等方差）+ **Cohen's d**（.2 小 / .5 中 / .8 大效应）
- 3组及以上：ANOVA 的 F、p、**η²**（.01 小 / .06 中 / .14 大效应），并给 **Bonferroni 校正的事后两两比较**（看具体哪两组不同）
- 结果导出"数据名_差异分析.csv"；t/F/p/d/η² 经 scipy 黄金对照逐位一致

**结果解读要点：**
- p < .05 才说差异显著；不显著就如实写"无显著差异"，不要硬找
- 报告格式：t(df)=X.XX, p=.XX, d=.XX；F(dfb,dfw)=X.XX, p=.XX, η²=.XX
- 前提：t/ANOVA 要求各组近似正态、方差齐性；严重不齐时 SPSS 看 Welch / Brown-Forsythe 行，脚本为等方差口径，结果以 SPSS/JASP 复核为准

**论文表述：**
"独立样本 t 检验显示，男女生在 XX 上差异不显著（t(df)=X.XX, p=.XX, d=.XX）。单因素方差分析显示，不同年级在 YY 上差异显著（F(dfb,dfw)=X.XX, p<.05, η²=.XX），事后比较表明 X 年级显著高于 Y 年级。"

## 六、中介效应检验（PROCESS宏）

### 前置：多重共线性诊断（VIF）
多元回归、中介（X 与多个 M 同时进入方程）前应先查共线性，避免系数不稳、符号反常。
- **脚本自动**：`auto_stats.py ... --x "X,M1,M2" --y Y` 的回归结果含每个预测变量的**容差**与 **VIF**（经 numpy 黄金对照）
- 判读：VIF<5 正常；5≤VIF<10 需关注；**VIF≥10（容差<0.1）为严重多重共线性**，应删除冗余变量、合并高度相关量表，或改用岭回归/分层回归
- SPSS：分析 → 回归 → 线性 → 统计 → 勾选"共线性诊断"，看容差与 VIF

### 安装PROCESS
1. 下载PROCESS宏（hayesprocess.com，免费）
2. SPSS → 实用程序 → 安装自定义对话框
3. 选择下载的process.spd文件
4. 安装后在"分析→回归"里能看到PROCESS

### 简单中介（模型4）
**操作步骤：**
1. 分析 → 回归 → PROCESS
2. 自变量（X）放入"自变量"
3. 因变量（Y）放入"因变量"
4. 中介变量（M）放入"中介变量"
5. Model number填4
6. Bootstrap samples填5000
7. Confidence level填95
8. 确定

**结果解读：**
- 总效应（c路径）：X对Y的总效应
- 直接效应（c'路径）：控制M后X对Y的效应
- 间接效应（a*b）：Bootstrap置信区间不包含0则显著
- 完全中介：直接效应不显著，间接效应显著
- 部分中介：直接效应和间接效应都显著

### 链式中介（模型6）
**操作步骤：**
- 同上，Model number填6
- 中介变量按链式顺序放入（M1在前，M2在后）

**结果解读：**
- 总间接效应：Bootstrap CI不包含0则显著
- 特定间接路径：
  - X→M1→Y（路径1）
  - X→M1→M2→Y（路径2，链式）
  - X→M2→Y（路径3）
- 每条路径的Bootstrap CI不包含0则该路径显著

**论文表述：**
"采用Hayes的PROCESS宏（模型6）进行链式中介效应检验，Bootstrap抽样5000次。结果显示，XX对YY的直接效应显著（β = .XX, p < .05）；XX→M1→M2→YY的链式中介效应显著（间接效应 = .XX, 95% CI = [.XX, .XX]，不包含0）。"

## 七、调节效应检验（PROCESS模型1）

**操作步骤：**
1. 分析 → 回归 → PROCESS
2. X放入自变量，Y放入因变量
3. 调节变量W放入"调节变量"
4. Model number填1
5. 勾选"条件效应"（Johnson-Neyman法）
6. Bootstrap 5000次
7. 确定

**结果解读：**
- 交互项（X×W）显著则调节效应存在
- 看简单斜率：在W的均值±1个标准差时，X对Y的效应是否显著
- b3>0 为增强型调节（W越高，X→Y越强）；b3<0 为缓冲型调节（W越高，X→Y越弱）

**脚本自动完成（PROCESS模型1）：**
```
python tools/auto_stats.py 数据.csv --scales scales.txt \
  --y 因变量量表 --x 自变量量表 --moderator 调节变量量表 --boot 5000
```
- 自动对 X、W **中心化**后构造交互项，回归给出 b0/b1/b2/b3、SE、标准化β、t、p 与 R²
- 输出 W 低（−1SD）/均值/高（+1SD）三水平的**简单斜率**、解析 SE、t、p 与 Bootstrap 95%CI
- 导出"数据名_调节效应.csv"；系数与简单斜率 SE 经 numpy 最小二乘黄金对照逐位一致
- **判读以 Bootstrap CI 是否含 0 为准**；若解析 p<.05 但 CI 含 0（边缘不一致），脚本会明确提示以 PROCESS 复核为准，不夸大结论
- 连续变量用中心化/标准化交互项；分类调节变量（如性别）应先做虚拟编码，建议直接在 SPSS PROCESS 中完成并出简单斜率图

## 九、网络分析（补充分析，可选）

### 适用条件
- 样本量 > 250
- 想展示变量间的整体关系结构

### R语言操作
```r
# 安装包
install.packages(c("qgraph", "bootnet"))

# 加载
library(qgraph)
library(bootnet)

# 估计网络（EBICglasso）
network <- estimateNetwork(data, default = "EBICglasso")

# 画图
plot(network, layout = "spring")

centralityPlot(network)
```

### 结果解读
- 节点：变量或维度
- 边：偏相关系数，越粗越强，绿色正相关，红色负相关
- 中心性指标：强度（strength）、接近性（closeness）、中介性（betweenness）
- 强度最高的节点是核心节点

## 十、统计结果报告规范

### 表格
- 用三线表
- 表号+表题在表格上方
- 均值标准差写成 M ± SD
- 相关矩阵标注显著性（*p<.05, **p<.01）

### 图
- 图号+图题在图下方
- 坐标轴有标签和单位
- 分辨率至少300dpi
- 黑白为主，不用花哨颜色

### 数字
- 小数保留2-3位
- p值：p < .05, p < .01, p < .001（不写p = .000）
- β、r、t、F、χ²等统计量保留2位小数
