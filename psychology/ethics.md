# 心理学研究伦理规范

> 本科毕业论文必须遵守的伦理要求。涉及人类被试的研究必须通过伦理审查。

## 一、知情同意

### 必须包含的内容
1. **研究目的**：简要说明研究是做什么的
2. **研究程序**：被试需要做什么、大约多长时间
3. **自愿原则**：参与完全自愿，可以随时退出，不会有任何惩罚
4. **匿名保密**：所有数据匿名处理，个人信息不会泄露
5. **风险说明**：研究可能带来的不适（如涉及敏感话题）
6. **联系方式**：研究者和指导教师的联系方式
7. **求助渠道**：如果研究引起不适，可以联系的心理援助热线

### 知情同意书模板
```
知情同意书

亲爱的同学：

你好！我是XX大学心理学专业的本科生，正在进行一项关于XX的毕业论文研究。

本研究采用匿名问卷调查的方式，大约需要10-15分钟。问卷内容包括你的基本信息以及对一些心理状态的自评。

参与本研究完全自愿，你可以随时退出，不会对你造成任何影响。所有数据仅用于学术研究，严格保密，不会泄露个人信息。

本研究涉及一些情绪相关的问题，如果你在填写过程中感到不适，可以随时停止。如有需要，可以拨打全国统一心理援助热线12356，或本校心理咨询中心电话：XX-XXXXXXX。

如果你同意参与，请点击"同意"开始填写问卷。

研究者：XXX
指导教师：XXX
联系方式：XXX
```

## 二、未成年人研究特殊要求

如果研究对象是中学生（未成年人），需要"三层同意"，缺一不可：

1. **监护人书面许可（parental permission）**：必须获得父母或法定监护人签署的书面同意
2. **未成年人本人同意（assent，与监护人同意分开）**：用适合其年龄和理解能力的通俗语言告知研究内容；中学生（约12岁及以上）应取得**书面 assent**，建议单独设计一页简短的"学生同意书"；7岁以下一般只需监护人许可，并做简单口头说明
3. **尊重未成年人的拒绝（dissent）**：即使监护人已经同意，学生本人明确不愿参与也必须尊重，不得勉强、不得追问原因
4. **学校同意**：通过学校发放问卷，需学校（并让相关班级班主任知情配合）批准
5. **风险加倍关注**：未成年人更易受影响，敏感话题要特别谨慎
6. **事后解释（Debriefing）**：研究结束后用通俗语言向被试说明研究目的，并再次提供求助渠道

> 说明：监护人许可解决"法定代理人是否允许"，未成年人 assent 解决"孩子本人是否愿意"，二者是两份独立的意思表示，不能互相替代。具体年龄分界和是否必须书面，以你校伦理审查要求为准。

### 监护人知情同意书模板
```
监护人知情同意书

尊敬的家长：

您好！我是XX大学心理学专业的本科生，正在进行一项关于XX的毕业论文研究。

您的孩子所在的学校将协助发放问卷。问卷为匿名填写，大约需要10-15分钟。所有数据仅用于学术研究，严格保密。

如果您同意您的孩子参与本研究，请签字确认。您和您的孩子都可以随时退出。

监护人签名：___________  日期：___________
学生签名：___________    日期：___________
```

### 学生本人同意（assent）简短模板（中学生，单独一页、用通俗语言）
```
同学你好：

我们想邀请你参加一份匿名问卷，了解同学们平时使用手机/AI和心情的一些情况，
大约需要10-15分钟。

· 参加完全凭你自己愿意，不愿意可以不参加，现在或中途想停下来都可以，
  不会告诉老师和家长你退出了，也不会影响你的成绩和任何人对你的看法。
· 问卷不写名字，答案没有对错，按你的真实想法填写即可。
· 里面有少数问题涉及不太愉快的话题，如果让你不舒服，可以随时停止；
  问卷最后留有心理援助热线，需要时可以拨打。

我已经知道上面的内容，我愿意参加：
学生签名：___________    日期：___________
```

## 三、敏感话题处理

### 涉及自伤、自杀等敏感话题时

1. **风险提示**：问卷开头明确说明"本问卷包含一些关于自伤行为的问题，可能引起不适"
2. **求助信息**：问卷开头和结尾都提供心理援助热线
3. **不做诊断**：问卷结果不用于临床诊断，不告诉被试"你有XX问题"
4. **研究前先定风险预案**：在开题/伦理审查阶段就写清"发现高危作答如何处理"，提前与学校心理老师或心理中心对接好转介路径、联系人和响应方式，不要等发现问题才临时找人
5. **及时转介**：如果发现被试有严重自伤或自杀倾向，按预案告知学校心理老师或专业机构；**若判断其有即刻危险（已准备行动、无法保证当下安全），立即拨打120或110，或陪同前往最近医院急诊/精神科，不要只依赖热线**
6. **事后关怀**：研究结束后提供心理健康资源
7. **校园投放伦理**：尽量避免班主任在场盯着作答，不与成绩、操行、奖惩挂钩；学生自愿退出要为其保密（不让老师/同学知道是谁退出），问卷由研究者或经培训的人员统一回收，减少"被看着填"的压力

### 常用心理援助热线（号码可能调整，正式写进问卷/同意书前请再核实一次官方信息）
- **全国统一心理援助热线：12356**（国家卫生健康委设置，2025年5月起全国各地原有心理援助热线统一接入、一号接通，作为首选号码；来源：国家卫健委国卫医政函〔2024〕259号）
- 北京心理援助热线（北京回龙观医院·北京心理危机研究与干预中心）：010-82951332（24小时）
- 希望24热线（社会公益热线）：400-161-9995
- 本校心理咨询中心电话：务必向学校心理中心核实后填写（校内响应通常更快，也便于后续转介）
- **紧急情况**：被试当下有即刻自伤/自杀危险时，直接拨打120或110、或前往最近医院急诊/精神科

## 四、数据伦理

### 数据收集
- 不收集不必要的个人信息（如身份证号、手机号、家庭住址）
- 匿名问卷不收集姓名
- 如果需要追踪（如纵向研究），用编码代替姓名

### 数据存储
- 原始数据加密存储
- 数据只保存在研究者的私人设备，不上传公共云盘
- 论文中只报告汇总数据，不出现个人信息
- 研究结束后，原始数据按学校规定妥善保存（毕业论文全套材料多要求保存至毕业后不少于5年，科研原始记录一般建议保存5-7年），具体年限以你校教务处/学院规定为准

### 数据使用
- 数据仅用于本研究，不用于其他目的
- 不将数据分享给未授权的人
- 如果需要共享数据，必须完全匿名化

## 五、学术诚信

### 数据
- 不伪造、不篡改数据
- 不选择性报告（显著的报，不显著的也报）
- 不删除不符合预期的数据，除非有明确的清洗标准

### 文献
- 所有引用的文献必须真实存在
- 不编造文献
- 引用格式规范

### 作者署名
- 毕业论文是独立完成的，学生是唯一作者
- 指导教师的贡献在致谢中说明
- 不抄袭、不代写

## 六、伦理审查

### 什么时候需要伦理审查
- 涉及人类被试的研究都需要
- 本科毕业论文一般由指导教师审核
- 部分学校有正式的伦理审查委员会，需要提交申请

### 伦理审查材料
- 研究方案
- 知情同意书
- 问卷全文
- 数据管理计划

## 七、常见伦理问题

| 问题 | 正确做法 | 错误做法 |
|---|---|---|
| 问卷太长 | 控制在60-80题，15分钟内 | 100+题，被试中途放弃 |
| 敏感题目 | 加风险提示和求助热线 | 直接问，不做任何说明 |
| 未成年人 | 监护人同意+本人同意 | 只让学生自己填 |
| 数据保存 | 加密、匿名、私人设备 | 上传公共网盘、发给别人 |
| 被试不适 | 提供求助渠道、允许退出 | 强迫填完 |
| 结果反馈 | 只给汇总结果，不做诊断 | 告诉被试"你有抑郁" |
