# 心理学常用量表库

> 本科毕业论文常用量表速查。所有量表信息需核实原文后使用。
>
> **使用约定**：本文件是按需查阅的专业参考，不替代 `core/coaching-protocol.md` 的带教规则与反馈三段式；与带教规则冲突时，以 core 规则与本文件红线中更严格者为准。表中信度/题数为速查值，正式使用以量表原文为准，不在场时标"需核实"、不凭记忆报数。

> **量表检索纪律（多词交叉，禁止单词下结论）**：本表只是起点，不代表"只有这些量表"。为每个变量找量表时，**至少用 3 组同义词/近义词、中英文、常见缩写、以及"代表作者 + 概念名"分别检索**（例：孤独感＝loneliness / lonesomeness / social isolation / UCLA Loneliness Scale / Russell 孤独）；检索式里**同一概念内用 OR 取并集、概念之间用 AND 取交集**，并跨知网/万方/Google Scholar/量表原文手册多个库。**只有多组词、多个库都查不到，才能判断"没有现成量表、需要自编"**，并把各组检索式与命中数写进检索记录留痕；单词 0 命中只是"这个词没命中"，不是"没有量表"。

## 量表选择原则

1. **优先选国内验证过的中文版** — 避免直接翻译的量表有文化偏差
2. **优先选题数少的** — 总问卷控制在60-80题
3. **优先选跟你样本匹配的** — 大学生样本就选大学生验证的量表
4. **信度α>.70可接受，>.80好，>.90优秀**
5. **必须找到原文确认题目和计分方式** — 不能只看综述里的描述
