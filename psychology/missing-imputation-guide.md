# 多重插补（MI）与全息极大似然（FIML）操作指引

> 配套 `tools/missing_report.py`（菜单第17项）：缺失值分析与 Little's MCAR 检验只回答"缺了多少、怎么缺"，**不替你插补**。本文件回答"检验之后怎么办"，给出 SPSS / R / AMOS 的可照做步骤、论文报告模板与红线。
>
> **使用约定**：本文件是按需查阅的专业参考，不替代 `core/coaching-protocol.md` 的带教规则与反馈三段式；与带教规则冲突时，以 core 规则与本文件红线中更严格者为准。
> 数据真实性是 P0 红线：不伪造数据、不为达到显著而删改数据或挑选插补方法/结果，"不显著也是结果"；发现学生有此意图时，按 `core/coaching-protocol.md` 的 P0 处置（明确拒绝＋说明后果＋给合规替代，如成列删除＋如实报告、敏感性分析、申请延期）。
>
> 方法学依据：Rubin (1987)；Schafer & Graham (2002, *Psychological Methods*)；Enders (2010, *Applied Missing Data Analysis*)；van Buuren (2018, *Flexible Imputation of Missing Data*, 2nd ed.)；Graham, Olchowski & Gilreath (2007)；von Hippel (2018)。具体菜单名随软件版本略有差异，以所用版本为准。

## 1. 先决策，再动手（决策树）

缺失机制（MCAR/MAR/MNAR）的含义见 `stats-guide.md` 与缺失分析工具报告。处理方式取决于**机制、缺失比例、完整样本是否还够功效**：

| 情形 | 推荐处理 | 说明 |
|---|---|---|
| 总缺失率 <5%，MCAR 未被拒绝，完整样本功效足够 | **成列删除（complete case）可接受** | 方法章写明完整 n、缺失率与 MCAR 检验结果；这是最透明、争议最小的做法 |
| 缺失 5%～10%，或 MCAR 被拒绝（提示 MAR） | **多重插补（MI）或 FIML 为主分析** | 成列删除可作为敏感性对照；不要只用成列删除 |
| 缺失 10%～20%，MAR | MI/FIML 主分析＋**敏感性分析**（见 §6） | 插补模型要纳入分析变量与辅助变量 |
| 缺失 >20%，或单变量缺失 >40%、整量表未答 | MI/FIML＋更充分的敏感性分析；考虑**剔除该变量/该批被试** | 插补造不出不存在的信息，高缺失下结论必须降级、局限写明 |
| 怀疑 MNAR（缺失与未观测到的值本身有关，如因症状太重而漏答） | MI/FIML 之外**必须**做 MNAR 敏感性分析 | MAR 假设无法用数据本身证明，见 §6 |

**本科论文务实建议**：总缺失率很低（<5%）且 MCAR 未拒绝时，不必硬上插补，成列删除＋清楚报告就是规范做法；上 MI/FIML 反而要多写一整套方法与敏感性说明。工具报告的建议是"倾向性提示"，不是必须执行的指令。

### 量表单题偶发缺失的特别说明

- 问卷量表个别题漏答（如 20 题量表漏 1～2 题），常用做法是**题均替代（person-mean substitution）**：用该被试在同一维度已答题的均分代替，再算量表分。它简单但会**人为压缩方差、虚高信度**；仅在缺失题少（一般每维度 ≤20% 题项）、该被试已答大部分题时作为描述性处理，并在方法章注明规则。
- 正式的推断统计（组间比较、相关、中介）优先对**题项数据做 MI/FIML**，不要对量表总分做均值插补。
- **成对删除（pairwise deletion）**在不同分析里用不同 n，会产生协方差矩阵非正定、结果互相矛盾，不推荐。

## 2. 红线（先看，任何软件都适用）

1. **禁止均值/中位数插补、LOCF（末次观测向前结转）、单点回归插补后直接当完整数据分析**：它们低估标准误、制造虚假精度（回归插补还会让 R² 虚高到接近 1）。
2. **禁止先看插补后结果是否显著、再回头换插补方法或删样本**；处理方案在分析前确定。
3. MI 不是"填一个最可能的值"：它生成 **m 个完整数据集**（每个的插补值带随机噪声），分别分析后按 **Rubin 规则池化**，把插补不确定性计入标准误。
4. MI 与 FIML 的标准假设是 **MAR**；MNAR 下任何方法都有偏，只能靠敏感性分析界定结论稳健性。
5. 插补模型要包含：①后续分析用到的**全部变量**（自变量、因变量、中介/调节、分组、交互项构成变量）；②与缺失有关的**辅助变量（auxiliary variables）**；③必要时纳入交互项/非线性项本身，不能只插补主效应。
6. 插补只用于**因缺失产生的空值**；99/77 之类无效码、乱答、规律作答应在清洗阶段先处理（见 `data_cleaner.py`），不能当缺失插补。
7. 插补后的数据不得用于"美化"结果：报告完整病例分析与 MI 分析两套结果，结论以稳健者为准。

## 3. SPSS 多重插补（菜单操作）

SPSS 自带多重插补（需"缺失值分析 Missing Values"相关组件，标准版以上含 Multiple Imputation 模块）。

1. **生成插补数据集**：菜单 `分析(Analyze) → 多重插补(Multiple Imputation) → 填充缺失值(Impute Missing Data Values)`。
2. 把所有分析变量与辅助变量选入"变量(Variables)"。
3. "插补(Imputations)"：默认 5，**建议改为 20 以上**（m 经验上不低于缺失率百分数，详见 §5；本科论文 m=20 通常足够并在方法章写明）。
4. "方法(Method)"：
   - 可选"自动(Automatic)"让 SPSS 按变量类型选模型；
   - 自定义时，连续/量表变量推荐 **预测均值匹配 PMM（Predictive Mean Matching，"尺度 Scale"变量选 PMM）**：插补值取自真实观测值，天然落在原量表取值范围（如 1～5），不会插出 2.7 分以外的怪值，适合 Likert 数据；线性回归(Linear Regression)适合近似连续、正态的变量。
5. "输出(Output)"选"创建新数据集/文件"，得到含 m 套完整数据的数据集（原始数据 + m 个插补版本，数据视图里按 Imputation_ 编号区分）。
6. **在插补数据集上跑分析**：SPSS 的回归、一般线性模型(GLM)、线性混合模型、Logistic 回归等过程会**自动识别 m 套数据并池化**，结果里出现"Pooled/池化"统计表（含 Rubin 规则合并的系数、标准误、df、p）。直接报告池化结果。
7. **不自动池化的过程**（含 Hayes PROCESS 宏、多数自定义宏、部分旧对话框）：
   - 方案 A（推荐）：中介/调节改用 R（lavaan + semTools 的 `runMI`，或 mice 配合中介包），或在 AMOS 里用 FIML（§4）；
   - 方案 B：对 m 个数据集分别运行，导出每次的效应量与标准误，按 §5 的 Rubin 公式手工池化（Excel 即可完成点估计、总方差与 t 检验）。

> 注：SPSS 版本不同，PMM 等选项的中文名与位置略有差异；找不到选项时用"自动"方法，并在方法章写"SPSS 多重插补，m=20，自动模型"。

## 4. AMOS 的 FIML（结构方程/中介模型首选）

FIML 不"填"数据，而是直接用全部观测到的原始似然估计模型，与 MI 同为 MAR 下的推荐方法，且在 SEM/中介框架里操作最简单：

1. 画好模型后，菜单 `View（视图）→ Analysis Properties（分析属性）→ Estimation（估计）` 选项卡；
2. 勾选 **"Estimate means and intercepts（估计均值与截距）"**——数据含缺失时，AMOS 即自动采用**全信息极大似然（FIML；输出中常标注为 ML、Maximum Likelihood with missing data）**；
3. 纳入**辅助变量**：与存在缺失的变量相关、但不属于假设模型的变量（如年龄、性别、其他量表分），用其与模型变量残差相关的方式纳入，可在 MAR 不严格成立时改善估计（这是 SEM 特有的便利，参见 Enders 辅助变量法）；
4. 结果读取与完整数据相同（路径系数、拟合指数、间接效应 bootstrap 均基于 FIML）；方法章写"采用全息极大似然估计（FIML）处理缺失，估计均值与截距，纳入 X 个辅助变量"。

## 5. R mice（代码模板，含 Rubin 池化公式）

```r
install.packages(c("mice"))        # 首次使用
library(mice)

# 1) 插补：m=20，连续/量表变量默认 pmm（预测均值匹配），固定种子可复现
#    data 里只放分析变量 + 辅助变量；无效码须先清洗为 NA
imp <- mice(data, m = 20, method = "pmm", seed = 20260918, printFlag = FALSE)

# 快速诊断：插补值分布应与观测值分布接近（stripplot/density 对比）
stripplot(imp, X1 ~ .imp, pch = 20, cex = 1.2)
densityplot(imp, ~ X1 | .imp)

# 2) 在每个插补数据集上跑同一模型（示例：线性回归；t 检验/方差分析同构）
fit <- with(imp, lm(Y ~ group + X1))

# 3) Rubin 规则池化
pooled <- pool(fit)
summary(pooled)          # estimate（池化系数）、std.error（含插补不确定性）、df、p
```

中介/SEM：

```r
# lavaan + semTools：FIML 与 MI 两种都可
library(lavaan); library(semTools)
model <- ' mediator ~ a*X
          Y ~ cprime*mediator + b*X
          indirect := a*cprime '
# MI 池化
fit.mi <- runMI(model, data = data, m = 20, miPackage = "mice", seed = 1,
                fun = "sem", estimator = "ml")
parameterEstimates(fit.mi, ci = TRUE, boot.ci.type = "perc")
# 或直接 FIML（等价于 AMOS 做法）
fit.ml <- sem(model, data = data, missing = "ml", fixed.x = FALSE)
```

**Rubin 池化规则（手工池化或核对软件输出时用）**：设第 i 个数据集的估计为 Q_i、标准误为 SE_i，共 m 个：

- 池化点估计：Q̄ = (1/m)·ΣQ_i
- 组内方差：Ū = (1/m)·Σ SE_i²
- 组间方差：B = (1/(m−1))·Σ(Q_i − Q̄)²
- **总方差：T = Ū + (1 + 1/m)·B**（比普通 SE 多出的 (1+1/m)B 就是插补不确定性）
- 检验：t = Q̄/√T，自由度用 Rubin/Barnard-Rubin 校正自由度（m 较小时明显小于普通残差 df；m≥20 且缺失不重时接近常规结果）；95%CI 用该 df 的 t 分布。
- 多参数检验（如整体模型、R² 变化）用 D 统计量（D1/D2/D3，mice 的 `pool.compare`/`D1`），不要逐系数手工拼。

**插补次数 m**：Rubin 早年 m=3～5 即可达到约 94% 效率；现代建议（Graham 等 2007；von Hippel 2018）在功效与可复现性上取 **m=20～100**，经验下限 m≈缺失率百分数（缺失 20% 时 m≥20）。m 越大池化结果越稳定、可复现；计算廉价时取 m=50 更稳。

## 6. 敏感性分析（MAR 假设的稳健性检查）

主分析用 MI/FIML 后，至少做一项并在结果/局限报告：

1. **完整病例对照**：成列删除样本重跑同一模型，比较系数方向、大小与显著性；结论一致则写"MI 与完整病例分析结论一致"。
2. **不同插补设置对照**：改 m（如 20 vs 50）、改方法（PMM vs 线性回归），结论应稳定。
3. **MNAR 情景分析**（缺失较重或怀疑 MNAR 时）：用 delta 调整/模式混合模型，给缺失者的插补值系统性加减一个量（如 0.2、0.5 个 SD 的不利偏移），观察结论在多大偏移处翻转（tipping point）；R 可用 `mice` + delta-adjustment 或 `naniar`/`rms` 相关流程。结论在合理偏移范围内不翻转，才可稳健陈述。
4. 报告插补诊断：插补值 vs 观测值的分布对比、各变量插补次数与收敛（mice 的 trace/density 图）。

## 7. 论文写法模板

**方法章（示例，按实际替换）：**

> 缺失值分析显示，K 个分析题项共 N 份记录中缺失单元格 X 个，总缺失率 X.XX%，完整作答 X 份（XX.X%）。Little's MCAR 检验 χ²(df)=XX.XX，p=.XXX（拒绝/未拒绝 MCAR）。为避免成列删除造成信息损失与偏差，本研究采用【多重插补/全息极大似然 FIML】处理缺失：【SPSS 多重插补，对连续与量表变量采用预测均值匹配（PMM），生成 m=20 个完整数据集，后续回归结果按 Rubin 规则池化 / AMOS 中估计均值与截距、采用 FIML，并纳入 X 个辅助变量】。插补模型纳入全部分析变量（含分组变量与交互项构成变量）。作为敏感性分析，另对完整病例样本重复主要分析，结果【一致/存在 X 处差异，详见表 X】。无效作答（规律作答、超时未答等）已在清洗阶段按预设标准剔除，未参与插补。

**结果章：**报告池化后的点估计、（总方差）标准误、校正 df、p 与 95%CI；表注注明"基于 m=20 重多重插补的 Rubin 池化结果"；同时一句话报告敏感性分析结论。

**局限章：**MI/FIML 依赖 MAR 假设，而 MAR 无法由数据本身证实；若缺失机制接近 MNAR，结果可能存在 X 方向的偏差；delta 敏感性分析显示结论在 ±X SD 偏移内保持稳定。
