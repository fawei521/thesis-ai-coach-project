# doubao-skill —— 豆包 Skill 版（轻量分发形态）

> 本目录是 **thesis-ai-coach 豆包 Skill 的权威源文件**，随完整版项目一起版本化管理。
> 完整版项目（START.md + tools/ + workflows/ + psychology/）面向"把整个文件夹交给 AI"的学生；
> 本 Skill 面向"在豆包里安装/启用技能即可被引导"的学生，**不含 Python 脚本**，但引导规则、阶段流程、学术口径与完整版一致。

## 目录与安装

```
doubao-skill/
├── SKILL.md              入口（frontmatter + 触发边界 + 启动协议）
├── CHANGELOG.md          Skill 独立版本历史
├── README.md             本文件（维护者读，不对学生朗读）
├── validate.py           结构自检（纯标准库，见下）
├── .skillignore
├── personalities/        default=默认自然风格；其余 3 个为可选人设（默认不加载）
├── stages/               12 阶段引导（stage-0 … stage-11），统一"准入→流程→准出"结构
├── references/           引导协议、鼓励系统、阶段速查、常识资料、维护者自测
└── templates/            进度文件模板（阶段 0 发给学生另存）
```

**安装/同步到豆包技能目录**：把本目录**内容**（不含本 README 也可，含之无害）复制到
`…/.doubao/agent_mode/workspace/.user_skills/thesis-ai-coach/`，保持 SKILL.md 位于该目录根部。

## 设计原则（改动时必须遵守）

1. **与完整版口径一致**：样本量（简单中介 ≥200、链式建议 ≥300）、五指标清洗、Harman <40%、Bootstrap 5000/95%CI、24 类答辩问题、12356 热线、未成年人 assent 等硬口径以完整版最新版为准；两边改动要互相追平。
2. **轻量版不假装拥有工具**：没有脚本就明说没有，需要自动化时指引完整版，禁止编造运行结果。
3. **默认自然风格**：不套人设；三种人设仅在学生主动选择时加载。
4. **鼓励系统默认打开、可关闭**：标准/精简/关闭三档，夸具体行为不夸天赋，P0 不用鼓励包装。
5. **不确定就标 `[需核实]`**：量表数字、文献、学校规定不得凭记忆给确定值。
6. **阶段文件统一结构**：阶段卡 → 准入检查 → 产出物 → 分步引导（导师动作/学生任务/检查点/鼓励时点）→ 卡点 → 红线 → 三闸准出。

## 自检与发布

每次改动后：

```
python doubao-skill/validate.py
```

退出码 0 才算通过（检查 frontmatter、必备文件、阶段编号连续性、三闸 checkbox、内部链接、鼓励开关、安全口径、占位符残留）。

完整版项目发布时（见根目录 DEVELOPMENT.md 阶段 G）：
1. 跑 `validate.py`；
2. 把本目录内容同步到 `.user_skills/thesis-ai-coach/`；
3. 在本文件同级 CHANGELOG.md 追加 Skill 版本条目（Skill 独立语义化版本，并注明"对应完整版 vX.Y.Z"）。
