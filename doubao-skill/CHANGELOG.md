# Skill 版本历史（thesis-ai-coach · 豆包 Skill 版）

> Skill 独立于完整版项目做语义化版本；每条注明对应的完整版版本。

## v1.1（2026-09-17，对应完整版 v1.55）：协议化、鼓励系统、默认自然风格

- **入口重构**：SKILL.md 增加触发边界（应触发/不应触发/复合请求）、4 项偏好一次性收集、文件加载规则、学生指令速查、运行铁律。
- **默认不套人设**：新增默认"自然专业风格"（personalities/default.md），原三种角色扮演改为**可选人设**（知心姐姐/严格导师/热情陪伴），默认不加载；同步降低人设文本的夸张感。
- **新增引导协议总纲** `references/coaching-protocol.md`：引导循环、P0/P1/P2 问题分级、三闸质量机制、三档难度、进度卡续接、决策协议、幻觉防范、工具安全、紧急模式（7/3/1 天）、心理危机与研究伦理安全、失败降级、产出前门禁。
- **新增鼓励与奖赏式反馈系统** `references/encouragement-guide.md`：标准（默认）/精简/关闭三档可切换；反馈三段式；里程碑奖赏；挫折时刻协议；四条心理学依据（正强化、成长型思维、反馈干预、自我决定理论）；P0 不包装。
- **12 阶段文件全部按统一模板重写**：准入检查、产出物、分步引导（导师动作/学生任务/检查点/鼓励时点）、卡点应对、红线、三闸准出；口径与完整版对齐（五指标清洗、功效样本量、Harman、Bootstrap、质量埋点、未成年人双同意、24 类答辩问题等）。
- **新增** `references/stage-checklist.md`（12 阶段准入/准出速查、跳阶段规则）与 `references/self-test.md`（26 条行为测试用例，维护者用）。
- **新增** `validate.py` 结构自检；新增 .skillignore。
- 参考资料更新：tools.md 改为 JASP/SPSS 并列并说明完整版工具链边界；faq.md 校正样本量与软件口径；academic-norms.md 的学校规定改为 `[需核实]` 口径。
