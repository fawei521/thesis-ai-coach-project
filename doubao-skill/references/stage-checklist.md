# 12 阶段准入 / 准出检查速查

> **文件定位**：一页式进度总表。判断学生真实阶段、申请跳阶段、过闸核对时用；详细引导在 `stages/stage-N-*.md`。
> **状态记号**：⬜未开始 / 🔄进行中 / ✅已过闸。过闸标准三句话：学生理解为什么做（动机）、产出达标可追溯（质量）、进度文件已更新（留痕）。

| 阶段 | 准入（进入前应具备） | 准出（三闸通过的硬标志） |
|---|---|---|
| **0 初始化** | 无 | 进度文件已建（含风格/难度/鼓励档偏好，风格未选=自然专业）；文件夹/文件命名规则明确；学生知道产出往哪存 |
| **1 选题** | 阶段0完成；知道专业与兴趣方向 | 变量具体到可测量（自变量/因变量/中介/调节）；研究模型与≥3条假设；中英文检索词已列；**学生亲自**在数据库验证创新性；已与导师沟通 |
| **2 文献检索** | 选题与关键词确定 | 30–50篇真实可查文献（中英文都有）；去重并按3–5主题分类；重点10–15篇标出；研究空白用自己的话说清 |
| **3 文献整理精读** | 文献已收集 | 文献信息表字段完整；10–15篇精读笔记（研究问题/方法/发现/与本研究关系/可借鉴点）；综述素材按主题归位 |
| **4 量表选择** | 研究变量确定 | 每个变量有≥2–3个量表对比（题数/维度/信度/验证样本/出处）；信息对照过原文 `[需核实]` 清零；授权要求明确；选择已获导师确认 |
| **5 问卷设计** | 各量表题目与计分方式核实 | 知情同意/指导语/人口学（最小化）/量表/结束语齐全；总量60–80题（约10–15分钟）；反向题标注；质量埋点（作答时长/1–2道注意力检查题/同设备限填一次）；敏感题有风险提示与12356；未成年人双同意方案；10–20人预测试（有时间时） |
| **6 方法与开题** | 研究模型确定 | 分析序列写清（描述→信度→效度→共同方法偏差→相关→差异→核心模型）；先验样本量估算（α=.05、功效=.8 + 无效卷冗余；链式中介建议≥300、最低200）；开题报告与PPT完成；模拟开题完成；方法经导师确认 |
| **7 数据收集** | 问卷定稿、通过预测试 | 有效样本达到估算量；多渠道、人口学分布可控；五指标剔除（时长过短/长直线/低变异/高缺失/注意力题答错）且标准收数前已定、有剔除明细；反向计分与量表总分完成；原始/清洗数据分开备份 |
| **8 数据分析** | 分析计划确定、数据清洗完成 | 描述统计→信度（α＋CITC＋分半）→效度（KMO/Bartlett；自编量表EFA）→Harman（首因子<40%）→相关→人口学差异/卡方→回归/中介（Bootstrap 5000，95%CI）/调节，逐步完成；效应量与CI齐全；三线表与模型图规范；**JASP/SPSS/PROCESS 复核口径**；不显著结果如实保留 |
| **9 论文写作** | 全部分析结果可解释 | 学生本人完成全文初稿（建议顺序：方法→结果→综述→引言→讨论→结论→摘要）；分章迭代≥2轮；引用真实且文后文内一一对应；格式/字数/三线表达标；查重与AI检测达标；AI使用声明按学校要求备好；导师看过并据反馈修改 |
| **10 跟老师沟通** | 全程适用，有关键节点需确认 | 每次沟通前：材料+选择题式提问+模拟问答；沟通后：反馈复述确认、行动清单、决策日志留痕；定期汇报不失联 |
| **11 答辩准备** | 论文终稿通过导师审核 | 10–15页PPT（每页一个核心信息）；5–10分钟发言稿；24类高频问题逐题准备（含伦理题）；至少1轮模拟答辩并按反馈改；答辩当天事项确认 |

## 跳阶段规则

学生说"我已经做过了"时：
1. 不准口头放行——要证据：上一阶段的产出文件/记录；
2. 抽查 2–3 个动机闸问题（"为什么这么选"），答不上就回补；
3. 质量闸按上表抽核关键字段；
4. 通过后在进度文件补登状态与决策日志；不通过则从缺口处继续，不重做已达标的部分。

## 全程红线（任何阶段都可触发 P0）

伪造/篡改数据、编造文献、代写正文、抄袭不标注、隐瞒学校要求的 AI 使用、未成年人研究无监护人同意、敏感研究无风险提示与求助渠道、为追求显著而剔除数据。
