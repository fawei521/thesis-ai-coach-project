# 参考资料：工具与环境

## 一、豆包（或同类 AI）使用入门

- 同一对话内有上下文记忆；换对话即"失忆"，靠 `我的论文进度.md` 续接
- 可上传 PDF、Word、图片、表格并读取内容
- 可操作虚拟电脑/浏览器（打开网页、检索、填表、整理文件），登录与验证码环节交还你本人
- 可生成文件（问卷、表格、网页、模型图、PPT 大纲等）
- 涉及账号密码的页面必须你亲手操作；AI 操作时你可以随时喊停；重要操作前先备份

## 二、知网（CNKI）登录路径

标准路径（各学校网站措辞略有差异）：
1. 打开学校图书馆官网（如九江学院 lib.jju.edu.cn）
2. 找"电子资源/数据库导航/文献资源"
3. 搜"中国知网"或"CNKI"，点"访问入口/校外访问"
4. 用学号与统一认证密码登录
5. 网址变成学校代理域名即说明有权限；代理地址会过期（数小时到数天），过期重新登录

使用纪律：
- 以题录、摘要为主，全文只下最相关的
- 单次登录全文下载不超过约 30 篇，24 小时控制在 30–50 篇以内
- 不整刊/整卷下载、不用迅雷等批量工具、不传播全文——过量下载可导致账号甚至全校 IP 被封

英文数据库：Google Scholar、PubMed、Web of Science、PsycINFO（按学校权限）；免费补充：Semantic Scholar、OpenAlex、CrossRef（验 DOI）、Connected Papers（找关联文献）。

## 三、软件选择建议

| 软件 | 用途 | 说明 |
|---|---|---|
| JASP（推荐，免费） | 信效度、t/方差、相关、回归、中介（内置 Mediation 或装 PROCESS 模块） | 界面与 SPSS 类似，免费开源，Mac/Windows 均可 |
| SPSS + PROCESS 宏 | 同上，中介/调节事实标准 | 学校机房常有授权；PROCESS 从官网 processmacro.org 下载，按教材安装 |
| G*Power（免费） | 样本量/功效估算 | 开题报告样本量依据 |
| Excel/WPS | 数据查看、简单整理、人口学频数 | 不做正式推断统计 |
| Zotero（免费） | 文献管理、一键抓题录、自动生成参考文献（GB/T 7714/APA 是引用样式） | 配 Word 插件插引用；浏览器插件抓网页题录 |
| Word/WPS | 论文排版 | 以学校模板为准 |

- 本科问卷研究：JASP 或 SPSS + PROCESS 足够，不需要 R/Mplus（网络分析、SEM 等补充分析除外，且要先与导师确认）
- 正式结果以公认软件输出为准；任何自写脚本/AI 算出的数字只用于预览，必须复核

## 四、完整版项目包（自动化工具链）

本 Skill 是**轻量版**，不含脚本。完整版 thesis-ai-coach-project 另带零门槛中文工具箱，适合需要自动化的同学：

- 问卷星原始答卷预处理、五指标数据清洗（附剔除明细）
- 一键统计（信度/效度/EFA/Harman/相关/差异/卡方/回归/中介/调节，自动出三线表与图）
- 样本量功效估算、模拟练手数据、英文文献检索、文献去重分类、模型图生成
- 双击「启动工具箱.bat」用中文菜单，无需记命令

获取完整版后，把项目文件夹交给 AI 并让其读取 START.md；本 Skill 的引导规则与完整版口径一致，两者可配合使用。是否需要、从哪里获取，问给你本 Skill 的维护者/老师。

## 五、其他可选工具

- NotebookLM（谷歌免费）：上传多篇 PDF 跨文献问答、生成综述大纲，需谷歌账号
- Obsidian：本地笔记与知识链接（配 Zotero 使用）
- 工具原则：为省时间而用，不为折腾而用；必须的只有"数据库 + 统计软件 + Word + 你自己的判断"
