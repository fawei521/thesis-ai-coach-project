# 参考资料：工具与环境

## 〇、手机上能用什么、不能用什么（先看这条）

| | 手机 | 电脑 |
|---|---|---|
| 上传 PDF/图片/表格让 AI 读 | ✅ | ✅ |
| AI 操作浏览器/虚拟电脑 | 看平台是否支持；**登录、验证码一律你本人做** | 同左 |
| 知网检索 | ✅ 手机浏览器、知网「全球学术快报」App | ✅ |
| 重点文献卡片网页 | ✅ AI 在对话给单文件 HTML，存手机用浏览器打开 | ✅ `literature_cards.py` 一键生成 |
| 生成问卷/大纲/表格/PPT 大纲文本 | ✅ | ✅ |
| **问卷星导出数据、预处理、清洗** | ⛔ 手机 App 能导出，但处理要在电脑 | ✅ |
| **统计分析（JASP/SPSS/PROCESS）** | ⛔ **装不了，必须电脑** | ✅ |
| **出图（碎石图/热图/模型图）** | ⛔ | ✅ |

> **一句话**：手机能走完"选题→收数据"和"写作→答辩"，**统计那一步必须回电脑**。
> 手机能力边界的完整说明见 `references/mobile-guide.md`。不要相信"手机上也能跑 SPSS"的说法。

## 一、豆包（或同类 AI）使用入门

- 同一对话内有上下文记忆；换对话即"失忆"，靠 `我的论文进度.md` 续接
- 可上传 PDF、Word、图片、表格并读取内容
- 可操作虚拟电脑/浏览器（打开网页、检索、填表、整理文件），登录与验证码环节交还你本人
- 可生成文件（问卷、表格、网页、模型图、PPT 大纲等）
- 涉及账号密码的页面必须你亲手操作；AI 操作时你可以随时喊停；重要操作前先备份

## 二、知网（CNKI）登录路径

标准路径（**各学校网站措辞略有差异，下面只是示例，请替换成你自己学校的入口**）：
1. 打开**你所在学校的**图书馆官网（示例：某校图书馆 `https://lib.<学校域名>`；具体域名以学校官网为准）
2. 找"电子资源/数据库导航/文献资源"
3. 搜"中国知网"或"CNKI"，点"访问入口/校外访问"
4. 用学号与统一认证密码登录（**手机浏览器同样适用**）
5. 网址变成学校代理域名即说明有权限；代理地址会过期（数小时到数天），过期重新登录

使用纪律：
- 以题录、摘要为主，全文只下最相关的
- 单次登录全文下载不超过约 30 篇，24 小时控制在 30–50 篇以内
- 不整刊/整卷下载、不用迅雷等批量工具、不传播全文——过量下载可导致账号甚至全校 IP 被封

英文数据库：Google Scholar、PubMed、Web of Science、PsycINFO（按学校权限）；免费补充：Semantic Scholar、OpenAlex、CrossRef（验 DOI）、Connected Papers（找关联文献）。

## 三、软件选择建议

> ⚠️ **下面除了问卷星/云笔记，全是电脑软件**——手机装不了。手机上走到这一步要先解决"去哪儿用电脑"。

| 软件 | 用途 | 说明 |
|---|---|---|
| JASP（推荐，免费） | 信效度、t/方差、相关、回归、中介（内置 Mediation 或装 PROCESS 模块） | 界面与 SPSS 类似，免费开源，Mac/Windows 均可（**电脑**） |
| SPSS + PROCESS 宏 | 同上，中介/调节事实标准 | 学校机房常有授权；PROCESS 从官网 processmacro.org 下载，按教材安装（**电脑**） |
| G*Power（免费） | 样本量/功效估算 | 开题报告样本量依据（**电脑**） |
| Excel/WPS | 数据查看、简单整理、人口学频数 | 不做正式推断统计；**桌面版**才适合处理后两份数据 |
| Zotero（免费） | 文献管理、一键抓题录、自动生成参考文献（GB/T 7714/APA 是引用样式） | 配 Word 插件插引用；浏览器插件抓网页题录（**电脑**） |
| Word/WPS | 论文排版 | 以学校模板为准（手机版可写草稿，定稿排版用电脑） |

- 本科问卷研究：JASP 或 SPSS + PROCESS 足够，不需要 R/Mplus（网络分析、SEM 等补充分析除外，且要先与导师确认）
- 正式结果以公认软件输出为准；任何自写脚本/AI 算出的数字只用于预览，必须复核

## 四、完整版项目包（电脑用，可选）

本 Skill **可以单独使用，不需要完整版**。本 Skill **不含脚本**（因此也不需要电脑、不需要装 Python）。
完整版 thesis-ai-coach-project 是**电脑上**的形态，另带零门槛中文工具箱，适合需要自动化的同学：

- 问卷星原始答卷预处理、五指标数据清洗（附剔除明细）
- 一键统计（信度/效度/EFA/Harman/相关/差异/卡方/回归/中介/调节，自动出三线表与图）
- 样本量功效估算、模拟练手数据、模型图生成
- **英文文献多词检索**：`paper_search.py` 支持每个概念多组近义词（`--query` 重复或 `--queries "词1;词2"`）、`--source all` 双源（OpenAlex/Semantic Scholar）、`--min 90` 自动翻页去重凑齐约 90 篇候选池
- **文献去重分类**（literature_organizer）与**重点文献卡片网页**（`literature_cards.py`：吃检索 CSV/整理表，去重后按重点/被引/相关度筛 10–20 篇，生成手机友好的单文件卡片 HTML）
- 双击「启动工具箱.bat」用中文菜单，无需记命令（**仅 Windows 电脑**）

**什么时候需要完整版**（满足任一条）：

1. 到了第 7–8 阶段要处理问卷数据、跑统计（**这是最常见的原因**）；
2. 要自动凑齐约 90 篇候选池、批量去重分类，或一键生成重点文献卡片网页；
3. 需要自动生成三线表、相关热图、碎石图、模型图；
4. 想用中文菜单而不想记命令。

完整版比本 Skill 多的是**脚本与图表能力**；**引导规则、阶段流程、学术口径两边一致**，
所以手机上走到哪一步，换到电脑可以从那一步接着走，不用从头来。
获取方式问给你本 Skill 的维护者/老师（本 Skill 不联网下载、不自动索取）。

## 五、其他可选工具

- NotebookLM（谷歌免费）：上传多篇 PDF 跨文献问答、生成综述大纲，需谷歌账号
- Obsidian：本地笔记与知识链接（配 Zotero 使用）
- 工具原则：为省时间而用，不为折腾而用；必须的只有"数据库 + 统计软件 + Word + 你自己的判断"
