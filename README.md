# Thesis AI Coach — 心理学毕业论文AI导师（超级向导）

> 一个AI可读取的毕业论文全程助手。学生下载后交给AI，AI自动扮演心理学毕业论文导师，从选题、开题、文献、问卷、数据分析、写作到答辩全程引导，并能自动检索文献、清洗数据、跑统计、生成图表和报告。

## 这是什么

这不是一个需要安装的软件，而是一个**AI可读取的项目包**。你把这个文件夹交给AI（豆包、ChatGPT等），AI读取 `START.md` 后自动成为你的毕业论文导师。

它有虚拟电脑（能操作网页）、自动化脚本（能跑统计、检索文献）、专业知识库（量表、统计、伦理），是一个覆盖论文全程的"超级向导"。

## 适合谁

- 心理学专业本科生
- 要做实证研究（问卷类）毕业论文
- 电脑小白也能用（手把手教装软件、跑工具）
- 想从选题到答辩全程有人带

## 怎么用（3步）

> 完全不懂电脑？先看 **`QUICKSTART.md`（快速上手）**，照着点就行。

1. **下载**整个项目文件夹，解压到电脑
2. **交给AI**：打开AI对话，上传整个文件夹（或 `START.md`）
3. **开始**：AI自动问你题目、进度、风格偏好，然后全程引导

你只需要跟AI说话。需要装软件、跑脚本、检索知网时，AI会一步步带你，或开虚拟电脑帮你做。不想记命令就双击「启动工具箱.bat」。换对话时把 `我的工作区/我的论文进度.md` 发给AI即可无缝续接。你自己的文献、数据、结果统一放进 `我的工作区/`（已建好分类子目录）。

## 自动化工具（tools/）

- `menu.py` + 根目录「启动工具箱.bat」 — **零门槛入口**，双击看中文菜单，文件可拖进窗口
- `wjx_preprocess.py` — 问卷星原始答卷预处理（中文表头/文本选项/"2分3秒"用时→标准数字表，附列映射报告）
- `paper_search.py` — 一键检索英文学术文献（免费API，无需key，返回真实文献和下载链接）
- `auto_stats.py` — 自动统计分析（人口学频数表、反向计分、信度α+逐题CITC/删题α题项分析表、结构效度KMO/Bartlett/因子载荷、`--efa`完整探索性因子分析(主成分+Varimax旋转+共同度+交叉载荷+Horn平行分析定因子数+自动碎石图PNG)、Harman共同方法偏差、量表总分、描述统计(偏度/峰度正态性)、M/SD/相关矩阵/α对角整合三线表、人口学差异(Levene方差齐性+独立样本t/Welch t/单因素ANOVA/Welch ANOVA+Cohen d/η²+Bonferroni事后，不齐提示Games-Howell)、多元回归(含容差/VIF共线性诊断)、Bootstrap中介模型4/6、调节效应模型1(中心化交互项+W均值±1SD简单斜率+Bootstrap CI，导出_调节效应.csv并出_调节效应_简单斜率图.png)；绘图（碎石图、简单斜率图）为可选依赖，未装matplotlib不影响数值结果）
- `generate_demo_data.py` — 生成内置链式中介的模拟问卷数据（练手/测试，严禁写进论文）
- `data_cleaner.py` — 问卷数据清洗（识别无效问卷）
- `literature_organizer.py` — 文献去重分类
- `chart_generator.py` — 研究模型图

**典型数据流水线**：问卷星导出 → 预处理 → 清洗 → 一键自动统计（频数/信度/效度/Harman/相关/回归/Bootstrap中介）→ JASP/SPSS复核 → 画模型图

## 4种导师风格

专业导师（默认，客观直接）/ 霸道总裁（自信果断）/ 知心姐姐（温柔耐心）/ 小奶狗（可爱热情）。说"换成XX风格"随时切换。

## 3种难度

入门（手把手）/ 进阶（给方向）/ 专家（只挑毛病）。

## AI不会做什么

- 不替你写论文正文、不编造文献和数据
- 不替你做决定（给选项让你选）
- 不碰你的账号密码（登录你自己操作）
- 不运行来源不明的脚本、不违反学术规范

## 版本

**v1.18 调节效应简单斜率图版**
- `--moderator` 自动出论文可用的简单斜率图（W 低/中/高三水平回归线，标注各斜率与显著性），复用碎石图中文字体与 matplotlib 软依赖（未装自动降级，不影响数值）

**v1.17 方差齐性＋Welch稳健检验版**
- 差异分析先做 Levene/Brown-Forsythe 方差齐性检验：2组方差不齐自动切 Welch t，3组及以上切 Welch ANOVA 并提示事后用 Games-Howell；`_差异分析.csv` 增方差齐性、稳健检验列
- Levene/Welch t 经 scipy、Welch ANOVA 经 Liu(2015)/R oneway.test 公式黄金对照逐位一致

**v1.16 共线性诊断版**
- 多元回归自动输出每个预测变量的容差与 VIF（<5正常/5–10关注/≥10严重），中介把 X 与多个 M 同时放入时可先查共线性；VIF 经 numpy 黄金对照

**v1.15 调节效应（PROCESS模型1）版**
- `--moderator 调节变量`：X、W 自动中心化＋交互项回归（b0–b3/SE/标准化β/t/p/R²），输出 W 低/均值/高三水平简单斜率（解析SE＋Bootstrap 95%CI），导出"数据名_调节效应.csv"
- 判读以 Bootstrap CI 是否含0为准；解析 p 与 CI 冲突时标"边缘、以PROCESS复核为准"，不夸大；系数与简单斜率SE经 numpy 黄金对照

**v1.14 人口学差异分析版**
- 自动识别人口学分组列（性别/是否独生子女等二分类、年级/生源地等多分类，兼容"男/女"文本），对每个量表总分：2组做独立样本 t＋Cohen's d，3组及以上做单因素 ANOVA＋η²＋Bonferroni 事后两两比较
- 导出"数据名_差异分析.csv"；t/F/d/η² 经 scipy 黄金对照逐位一致；演示数据补性别/年级列（独立随机，不改变既有统计基准）

**v1.13 正态性＋描述/相关/α整合三线表版**
- 描述统计新增 SPSS 口径**偏度/峰度与正态性判读**（Kline |偏度|<3、|峰度|<10，明显偏态走 Bootstrap），经 scipy 黄金对照逐位一致
- `_统计结果.csv` 升级：表1描述+正态性；**表2为论文标准"描述统计＋相关矩阵＋信度"整合表（M/SD、下三角相关带星号、对角 α）**；表3相关明细含双尾 p

**v1.12 题项分析（CITC＋删题α）版**
- 信度分析从"只报总α"升级为逐题输出 **CITC 校正项总相关**与**删题后α**，自动标记 CITC<.40、删题后α升高的题
- 导出"数据名_题项分析.csv"（UTF-8-SIG，可直接整理成信度三线表）；2题量表删题α正确显示 NA 不崩溃
- CITC 与删题α经 Wolfram 小样本整数例黄金对照，逐位一致

**v1.11 Horn平行分析版**
- `--efa` 新增 Horn 平行分析（默认500次随机模拟）：给出随机特征值均值/95%分位与建议因子数，因子数判定从"特征值≥1"升级为 Kaiser＋碎石拐点＋平行分析＋理论四依据
- 碎石图叠加平行分析随机均值线（橙）与95%分位线（紫），一张图同时是碎石图与平行分析图，可直接插入论文
- `--pa-rep 次数` 可调模拟次数、`--pa-rep 0` 关闭；随机相关矩阵特征值经 Wolfram 黄金对照，纯随机数据不误判因子

**v1.10 EFA碎石图自动出图版**
- `--efa` 现在除数值结果外，为每个量表自动导出"数据名_量表名_碎石图.png"（300dpi，含 Kaiser λ=1 参考线、保留因子高亮、特征值标注、拐点清晰），可直接插入论文
- matplotlib 为可选依赖：未安装时仅提示安装，数值结果与退出码不受影响（优雅降级）
