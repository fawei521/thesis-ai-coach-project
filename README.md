# Thesis AI Coach — 心理学毕业论文AI导师（超级向导）

> 一个AI可读取的毕业论文全程助手。学生下载后交给AI，AI自动扮演心理学毕业论文导师，从选题、开题、文献、问卷、数据分析、写作到答辩全程引导，并能自动检索文献、清洗数据、跑统计、生成图表和报告。

## 这是什么

这不是一个需要安装的软件，而是一个**AI可读取的项目包**。你把这个文件夹交给AI（豆包、ChatGPT等），AI读取 `START.md` 后自动成为你的毕业论文导师。

它有虚拟电脑（能操作网页）、自动化脚本（能跑统计、检索文献）、专业知识库（量表、统计、伦理），是一个覆盖论文全程的"超级向导"。

## 适合谁

- 心理学专业本科生
- 要做实证研究（问卷类）毕业论文
- 电脑小白也能用（手把手教装软件、跑工具）
- 想从选题到答辩全程有人带

## 怎么用（3步）

1. **下载**整个项目文件夹，解压到电脑
2. **交给AI**：打开AI对话，上传整个文件夹（或 `START.md`）
3. **开始**：AI自动问你题目、进度、风格偏好，然后全程引导

你只需要跟AI说话。需要装软件、跑脚本、检索知网时，AI会一步步带你，或开虚拟电脑帮你做。

## 全程能力

| 阶段 | AI能帮你做什么 |
|---|---|
| 选题 | 给选题方向、验证创新性、检索英文文献 |
| 开题 | 开题报告模板、开题PPT、模拟开题问答 |
| 文献 | 自动操作知网检索、英文API检索、PDF结构化分析、研究空白梳理 |
| 量表 | 20+量表对比、信效度信息、问卷生成 |
| 数据 | 自动清洗、反向计分、算总分 |
| 分析 | 自动跑信度/描述/相关/回归、生成三线表、指导中介分析、画模型图 |
| 写作 | 大纲、各章节要点、语言润色、格式检查、去AI味 |
| 答辩 | PPT大纲、发言稿、20个高频问题、模拟答辩 |

## 自动化工具（tools/）

- `paper_search.py` — 一键检索英文学术文献（免费API，无需key，返回真实文献和下载链接）
- `auto_stats.py` — 自动统计分析（信度α、描述统计、相关矩阵、回归、三线表）
- `data_cleaner.py` — 问卷数据清洗（识别无效问卷）
- `literature_organizer.py` — 文献去重分类
- `chart_generator.py` — 研究模型图

## 工作流手册（workflows/）

- `environment-setup.md` — Python/JASP/Zotero/Obsidian零门槛安装
- `literature-auto-search.md` — 知网浏览器自动化 + 英文API检索
- `paper-reading-guide.md` — 论文PDF的IMRaD结构化分析
- `toolchain-guide.md` — Zotero+Obsidian文献管理工具链
- `data-analysis-auto.md` — 数据分析全流程
- `proposal-guide.md` — 开题报告专项
- `defense-guide.md` — 毕业答辩专项
- `writing-guide.md` — 论文写作辅助

## 专业知识库（psychology/）

- `scale-library.md` — 20+心理学常用量表（题数、维度、信度、出处）
- `stats-guide.md` — 10种统计方法的SPSS/JASP操作步骤
- `ethics.md` — 研究伦理（知情同意、未成年人、敏感话题）

## 4种导师风格

专业导师（默认，客观直接）/ 霸道总裁（自信果断）/ 知心姐姐（温柔耐心）/ 小奶狗（可爱热情）。说"换成XX风格"随时切换。

## 3种难度

入门（手把手）/ 进阶（给方向）/ 专家（只挑毛病）。

## AI不会做什么

- 不替你写论文正文、不编造文献和数据
- 不替你做决定（给选项让你选）
- 不碰你的账号密码（登录你自己操作）
- 不运行来源不明的脚本、不违反学术规范
