# Thesis AI Coach — 心理学毕业论文AI导师

> 一个AI可读取的毕业论文导师系统。学生下载后交给AI，AI自动扮演心理学毕业论文导师，从选题到答辩全程引导。

## 这是什么

这不是一个软件，也不是一个网站。这是一个**AI可读取的项目包**。

你把这个文件夹交给AI（比如豆包、ChatGPT），AI读取后会自动变成你的毕业论文导师，引导你完成心理学本科毕业论文的全部流程。

## 适合谁

- 心理学专业本科生
- 要做实证研究（问卷类）毕业论文
- 不知道从哪开始、需要有人一步步带
- 电脑小白，不想装复杂软件

## 怎么用（3步）

### 第1步：下载
下载整个项目文件夹，解压到电脑上。

### 第2步：交给AI
打开AI对话（豆包/ChatGPT等），把整个文件夹（或 `START.md` 文件）上传给AI。

### 第3步：开始
AI读取后会自动问你几个问题（题目、进度、风格偏好），然后开始引导。

你只需要跟AI说话，它会告诉你下一步做什么。

## AI导师能做什么

- 帮你想选题、验证创新性
- 指导文献检索和整理
- 帮你选量表、设计问卷
- 教你做统计分析（SPSS操作步骤）
- 帮你改论文语言、查逻辑
- 模拟答辩、准备问答
- 处理各种突发问题（结果不显著、样本不够、老师否定选题）

## AI导师不会做什么

- 不会替你写论文正文
- 不会编造文献或数据
- 不会替你做决定（给选项让你选）
- 不会违反学术规范

## 4种导师风格

1. **专业导师**（默认）— 客观直接，只讲干货
2. **霸道总裁** — 自信果断，"听我的"
3. **知心姐姐** — 温柔耐心，先共情再给方法
4. **小奶狗** — 可爱热情，主动帮你做杂活

随时可以切换，跟AI说"换成XX风格"就行。

## 3种难度

- **入门** — 手把手教，每步给具体操作
- **进阶** — 给方向，自己操作
- **专家** — 只挑毛病，讨论深度问题

## 注意事项

1. AI是辅助工具，论文必须自己写
2. 所有文献和数据必须自己核实
3. 涉及敏感话题（自伤等）注意伦理
4. 跟导师沟通比跟AI沟通更重要
5. 遇到AI不确定的事，问你的指导老师
