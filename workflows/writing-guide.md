# 论文写作辅助指南

> AI在写作阶段的角色：帮你搭骨架、改语言、查逻辑、查格式；也可按你的真实材料起草可编辑草稿，但必须逐段标注“AI 草稿”、报告风险，你逐句核实并用自己的话改写后才能用——定稿必须是你自己的。
> 本指南给出各章节写作要点、学术语言规范、格式检查、查重与AI检测应对。
>
> **带教约定**：本文件只提供本主题的专业步骤；每轮对话仍按 `core/coaching-protocol.md` 走引导循环、反馈三段式与 P0/P1/P2 分级，鼓励按 `core/encouragement-guide.md`（默认标准档，学生说"关闭鼓励"即关）；属于正式阶段的，收尾过 `core/coach-rules.md` 第十一节三道闸。

---

## 一、写作总原则

1. **先有结果，再写论文**：数据分析完成、结论清楚后再动笔
2. **建议写作顺序**：方法 → 结果 → 文献综述 → 引言 → 讨论 → 结论 → 摘要（从最好写的部分开始）
3. **AI只改不写**：你写初稿，AI帮你润色语言、检查逻辑、发现漏洞
4. **每段有主旨**：每段第一句是观点，后面是证据和解释
5. **所有观点有出处**：事实性陈述、前人结论必须引用文献

## 二、各章节写作要点

### 摘要（最后写，300-500字）
结构：目的（1句）→方法（对象、工具、分析）→结果（关键系数）→结论（1句）
- 结果部分要写具体数字
- 关键词3-5个，用分号隔开

### 引言（1500-2000字）
- 漏斗结构：大背景 → 聚焦现象 → 提出问题 → 本研究做什么
- 不要在引言写太多具体研究（那是综述的内容）
- 结尾自然引出研究问题和意义

### 文献综述（2000-2500字）
- **按主题组织，不按作者罗列**
  - 错误示范："张三认为……李四指出……王五发现……"
  - 正确示范："关于X与Y的关系，多数研究发现……（张三，2023；李四，2024），但也有研究……"
- 每个变量：概念界定 → 测量 → 相关研究
- 结尾必须有"研究述评/研究空白"，自然过渡到你的假设
- 引用要会转述，不要大段直接引用

### 研究方法（1500-2000字）
- 目标：让别人能重复你的研究
- 对象、工具、程序、数据处理四部分
- 量表信息完整（名称、作者年份、题数、维度、计分、信度）
- 用过去时、客观语气

### 研究结果（2000-2500字）
- 只报告结果，不解释原因（解释放讨论）
- 顺序：共同方法偏差→信效度→描述统计与正态性→人口学差异（t/方差分析/卡方等）→相关→回归/中介/调节
- 每个结果：先文字描述，再"如表X所示"，最后报告统计量
- 相关矩阵可用工具自动生成的下三角热图作为插图（对角为α、下三角为系数与显著性），但正式数值仍以三线表为准
- 统计表述规范：
  - "M±SD"报告均值标准差
  - 相关：r = .32, p < .01
  - 差异：t(df) = x.xx, p = .xxx，或 F、非参数检验 U/H
  - 中介：间接效应 = .XX，95% CI [.XX, .XX]，不含0
  - 调节：交互项显著后报告简单斜率，可配简单斜率图
- 图表编号连续，正文必须引用每个图表

### 讨论（1500-2000字）
- 第一段：总结主要发现
- 逐条讨论：结果说明什么、和谁的研究一致/不一致、为什么
- 理论意义 + 实践启示
- 局限（诚实但不过度自贬）
- 未来研究方向

### 结论（200-300字）
- 2-3句话，不引入新内容、不引用文献

## 三、学术语言规范

### 用词
- 客观中立，避免"我认为""我觉得"，用"本研究发现"
- 避免口语："搞""弄""特别好" → "进行""实施""显著"
- 避免绝对化：不用"证明了"，用"支持了""结果表明"
- 横断研究不用"导致""因果"，用"预测""关联"

### 人称与时态
- 方法、结果用过去时（"本研究采用了……"）
- 讨论普遍规律可用现在时
- 可用"本研究"，少用第一人称"我"

### 常见语言问题
| 不规范 | 规范 |
|---|---|
| 显著相关 | 呈显著正相关/负相关 |
| p<0.05很显著 | p < .05，差异具有统计学意义 |
| 证明了因果 | 支持了……的假设/与……一致 |
| 数据证明 | 结果显示/结果表明 |
| 大概、可能（无依据） | 删除或补充依据 |

### 把文字改回你自己的口吻（四步，重要）
AI 写的东西一眼能认出来，是因为它**只做概括、不做现场**：句子一样长、要点凑成三、评价词多、数字少。
改法按这四步走，一步都不能省（**AI 不能替你走这四步**——它替你改完，还是它的话）：
1. **逐句读**：读出声。凡是"这句我为什么要写"答不上来的，先标出来再决定删还是重写。
2. **换成只有你写得出的具体信息**：把"具有深远影响"换成你的样本量、α、哪所学校、哪个年级、
   施测时出了什么岔子、导师哪句话让你改了方案。**这一步是判据**——改完的段落里应当有
   只有作者本人写得出的细节；没有，就是还没改完。
3. **打乱一样长的句段**：长段拆开、短句加进去、别每段都用"本研究…"起头、要点别硬凑三条。
4. **AI 退到校对位**：让它查语病、查逻辑断点、查引用格式，**不让它生成再让你顺一遍**。

自查工具：菜单第 24 项（`python tools/style_check.py 你的稿子.md`）会把上面这些抓出来给你看位置，
它**只报问题、不替你改**。

> **两条如实说在前面的边界**：
> ① 这四步**不测 AIGC 率、也不承诺任何检测结果**。想把数字压下去不是本包的目标（见 `core/ai-literacy.md` 第八节）。
> ② 用了 AI 就如实申报（`templates/ai-usage-declaration.md`）；过程证据靠菜单第 25 项的写作留痕。

## 四、引用与参考文献规范（GB/T 7714-2015）

### 正文引用
- 直接引用：作者（年份）认为"……"（页码）
- 间接引用：……观点（作者，年份）
- 多作者：（张三等，2024）/（Smith et al., 2023）

### 参考文献格式（GB/T 7714-2015 顺序编码制）
- 期刊[J]：[1] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页.
- 专著[M]：[2] 作者. 书名[M]. 出版地: 出版者, 年.
- 学位论文[D]：[3] 作者. 题名[D]. 城市: 学位授予单位, 年.
- 会议论文[C]：[4] 作者. 题名[C]//论文集名. 出版地: 出版者, 年: 起止页.
- 报纸[N]：[5] 作者. 题名[N]. 报纸名, 出版日期.
- 电子资源[EB/OL]：[6] 作者. 题名[EB/OL]. (更新日期)[引用日期]. URL.
- 著者规则：1-3 人全列；≥4 人列前 3 人后加"等"（英文 et al）；欧美著者姓在前、名缩写不带点（如 HENSELER J, RINGLE C M）；有 DOI 时著录在末尾（DOI:10.xxxx）。
- 用 Zotero 自动生成，或用本项目工具 `reference_formatter.py` 统一格式化；无论哪种方式都要人工逐条核对。

### 用工具一键格式化（菜单第 16 项）
- 题录整理成 CSV：可直接用菜单第 4 项 paper_search 的导出、第 5 项文献整理表；或先运行
  `python tools/reference_formatter.py --save-template 参考文献模板.csv` 取得带 4 个示例行的空白模板
  （13 列：类型/作者/题名/年份/刊名·论文集·报纸/卷/期/页码/出版地/出版社·学位单位/URL/DOI/更新日期）。
- 运行：`python tools/reference_formatter.py 文献.csv`（菜单第 16 项有交互引导，可直接拖文件），默认在同目录输出 `文献_参考文献.txt`。
- 学校模板要求全角标点加 `--fullwidth`；按 GB/T 7714-2025 新口径（外国作者姓氏首字母大写而非全大写）加 `--name-case 2025`；电子资源 [引用日期] 默认今天，可用 `--access-date 2026-09-18` 指定；不要编号加 `--no-number`。
- 缺字段不会被静默编造：文中以【待补：xx】标出并在控制台逐条列出，补全后重跑；无法判断类型的条目直接中文报错退出（rc=1）。UTF-8/GBK 编码都能读。
- 工具只做格式化，不联网、不生成文献。

### 引用红线
- 引用的文献必须真实存在、自己读过
- 不能让AI编造引用（AI可能生成不存在的文献）；格式化工具同样不产出任何"新"文献，只重排你给的真实题录
- 参考文献数量本科一般30-50篇，近5年占50%以上，中英文结合
- 正文引用编号与文末列表必须一一对应；工具按 CSV 行序编号，定稿调整引用顺序后重跑

## 五、格式检查清单

- [ ] 字体字号符合学校要求（正文一般宋体小四/12号，1.5倍行距）
- [ ] 页边距、页码、页眉页脚正确
- [ ] 标题层级清晰（1 / 1.1 / 1.1.1）
- [ ] 表格三线表，表题在上方
- [ ] 图题在下方，图清晰（300dpi）
- [ ] 图表编号连续且正文都有引用
- [ ] 统计量斜体规范（M、SD、r、p、β、N等斜体）
- [ ] 参考文献格式统一、与正文一一对应
- [ ] 无错别字、标点统一（中文用全角）
- [ ] 摘要、目录、正文页码正确

## 六、查重与AI检测

### 查重（文字重复率）
- 学校一般要求重复率 < 10%-30%（看具体要求）
- 降重方法：
  - 用自己的话转述，不照抄
  - 直接引用改间接引用并加引用标注
  - 增加自己的分析和例子
  - 专业术语保留，句式结构重写
- 不要用"中译英再译中"等投机方法，语句会不通顺

### AI检测（AIGC 检测）
- 部分学校会做 AIGC 检测并设比例要求——**先拿到本校原文**（比例、用什么系统、误伤了怎么办），拿不到就标 `[需核实]`，别套别的学校的数字
- **本包不做"降率""过检测"**，也不给你洗句式的步骤（理由见 `core/ai-literacy.md` 第八节）。真正管用的三件：① 按第三节四步把文字改回你自己的口吻（AI 味本质是没有你的具体信息）；② 菜单第 24 项自查＋第 25 项留痕，攒过程证据；③ 用了 AI 就如实申报
- 检测系统之间结果不一致、误伤真人写作是常事。**别为压一个不可靠的数字把论文改坏**；真被误伤，拿得出来的是你的草稿版本与留痕，不是一套更像人的句式
- 如实填写AI使用声明（见 templates/ai-usage-declaration.md）

### 学术诚信底线
- 不买论文、不全文代写代交（AI/他人文字不改不核实直接交）、不伪造数据、不编造文献
- AI是工具，论文的思想和表达必须是你自己的

## 七、AI在写作中的正确用法

| 可以让AI做 | 不能让AI做 |
|---|---|
| 根据你的真实材料与要点起草可编辑段落（AI 须标注草稿、逐段报告风险），你再逐句核实重写 | 直接生成整段正文照抄、不改不核实 |
| 润色语言、改语病 | 编造文献和数据 |
| 检查逻辑漏洞、结构问题 | 替你形成观点和结论 |
| 解释统计结果含义 | 替你解读成你不懂的结论 |
| 模拟审稿挑毛病 | 把AI文字不加修改直接交 |
| 规范引用格式 | 生成虚假引用 |
