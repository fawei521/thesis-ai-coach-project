# 跟老师沟通指南（全程）

> 毕业论文不是你一个人闷头做，而是在导师指导下完成。会不会沟通，直接决定老师愿不愿意帮你、你的问题能不能及时解决。
> 本指南给原则、节奏和可以直接套用的话术。【】里的内容换成你自己的，不要原封不动照抄。

---

## 一、五条核心原则

1. **带选择题，不带问答题**
   不要问"老师我做什么题好"，而是先做功课，给 2–3 个方案，每个写清变量、依据、难点，让老师做选择或修正。老师指导的是"有准备的学生"。

2. **定期露面，不要失联**
   建议每 2–3 周主动汇报一次，至少每个关键节点（定题、开题、收数、出结果、初稿、定稿）汇报一次。哪怕没做完，也汇报"做了什么、卡在哪、下一步"。长期失联是导师最反感的事。

3. **对事不对人，先接住再讨论**
   老师批评你的稿子，不等于否定你这个人。被否定时先确认问题、别当场顶回去；想清楚后，有依据地表达不同意见。

4. **一次只问清楚一件事，问题要具体**
   把大问题拆成可回答的小问题，并附上你已经查到的信息和你的初步判断。例如不要问"中介分析怎么做"，而问"我这个链式中介打算用 PROCESS 模型6、Bootstrap 5000，您看是否合适"。

5. **全程留痕**
   重要决定（题目、量表、样本量、方法、老师口头意见）尽量用文字确认（微信/邮件/会议纪要），沟通后在 `我的工作区/我的论文进度.md` 的"关键决策日志"记一笔，避免日后"老师说过/没说过"扯皮。

---

## 二、沟通节奏（什么时候该找老师）

| 节点 | 要不要找老师 | 沟通目标 |
|---|---|---|
| 定题前 | 必须 | 确认选题方向成立、无硬伤 |
| 选题初步成形 | 必须 | 确认题目、变量、模型 |
| 选量表时 | 必须 | 请老师确认量表是否合适、是否需授权 |
| 开题报告前 | 必须 | 先给老师看一稿，避免开题现场被否 |
| 设计问卷/伦理 | 建议 | 未成年人样本、敏感题、知情同意务必先过老师 |
| 收数困难 | 及时 | 早说，一起想渠道或调整样本/方法，不要拖 |
| 结果出来 | 建议 | 确认分析方向、不显著结果怎么处理 |
| 初稿/每轮修改稿 | 必须 | 按老师节奏提交、修改 |
| 答辩前 | 必须 | 模拟、确认 PPT 和口径 |

> 经验：问题越早暴露成本越低。收不够数据、选题被否这类问题，提前三周说和提前三天说，结果完全不同。

## 三、分场景话术模板

> 话术是骨架，务必结合你的真实情况填，不要群发感、不要造假。

### 场景1：第一次联系导师（邮件/微信）

```
X老师您好，我是【心理学专业X班】的【姓名】（学号【】），
您是我毕业论文的指导老师。我的初步方向是【一句话方向，如AI使用与青少年心理健康】。
想约您【周X上午 / 周X下午】（任选您方便的时间，我这几个时段都可以）当面或线上汇报一次，
听听您对选题的意见。附件是我初步整理的方向说明。打扰老师了，谢谢！
```

### 场景2：确认选题（带方案的选择题）

```
老师好，关于毕业论文选题，我查了中英文文献，整理了3个方向，想请您帮我把把关：

A.【题目/变量组合】——依据【1-2篇代表文献/现象数据】，优点是【】，难点是【】
B.【…】——…
C.【…】——…

我个人倾向A，因为【新在哪、可行性如何】。直接做这个完整模型组合的研究我暂未检索到，
但类似路径（【如手机依赖→孤独→反刍→NSSI】）已有验证。
想请您看：①这几个方向哪个更值得做？②样本用【大学生/中学生/混合】是否可行？
③有没有我没考虑到的硬伤？
```

### 场景3：确认量表

```
老师好，关于【自变量/因变量】的测量，我对比了几个成熟量表：
【量表A】：【题数】题、【维度】、α【】、【作者年份】、有中文版验证；
【量表B】：…
我倾向用【A】，理由是【题数少/有同人群验证/与本研究匹配】。
量表原文和出处我已找到（附对比表）。想请您确认是否合适；
如果该量表声明需要授权，我会提前邮件向作者申请并留存回复。
```

### 场景4：开题报告提交前

```
老师好，这是我按上次意见修改的开题报告（附件：姓名-题目-开题报告-版本-日期）。
这次主要改了【研究空白表述/样本量依据/技术路线】。
想请您重点帮我看：①研究方法和统计方案是否站得住；②创新点表述是否过头；
③开题时可能被问到的薄弱处。我计划【日期】开题，想提前按您意见再改一版。
```

### 场景5：涉及未成年人/敏感话题的伦理确认（重要）

```
老师好，我的样本涉及【中学生/未成年人】，问卷含【自伤/情绪】类敏感题。
我准备：①取得监护人书面知情同意＋学生本人同意＋学校批准；
②问卷首尾放风险提示和全国统一心理援助热线12356及学校心理中心电话；
③全程匿名、不做临床诊断、发现高危个体转介学校心理老师。
想请您确认这套伦理流程是否符合学校要求、是否需要先走伦理审查（备案）。
```

### 场景6：数据收不够 / 样本不达标（越早说越好）

```
老师好，跟您同步进度并求助：目前回收【】份、有效【】份，
距离目标【】份还差【】，主要困难是【渠道有限/中学生发放需审批】。
我想到几个办法：①请实习学校/带教老师协助转发；②延长【】周；
③在您同意下把样本范围调整为【】。想听听您的建议，必要时能否请您帮忙协调发放渠道？
```

### 场景7：提交初稿（说清审阅重点）

```
老师好，我的论文初稿已完成（附件：姓名-题目-初稿-日期），全文约【】字。
这一版我自己最没把握的是【第四章数据分析/讨论部分】，
想请您重点看：①整体框架和论证逻辑；②【具体章节】。
我知道还比较粗糙，您指出问题我再逐条修改，辛苦老师了！
```

### 场景8：回复修改意见（复述＋说明改法＋引导下一步）

```
老师好，谢谢您的修改意见，我逐条核对了，准备这样改：
1. 关于【意见1】，我已【具体怎么改/改在哪一页】；
2. 关于【意见2】，我的理解是【复述确认】，打算【改法】，如果理解有偏差请您纠正；
3. 【某条意见】我查了文献后有一点不同想法：【依据】，想和您再确认一下。
改完后我会发您修改稿，并附一份"意见-修改对照"。
```

### 场景9：礼貌催稿（给客观时间，不催逼）

```
老师好，打扰您了。想请问我【日期】发您的【初稿/开题】您是否已方便查看？
因为学校要求【X月X日】提交系统，我担心后续按意见修改的时间不够，
所以跟您确认一下，您看我需要先就哪一部分着手调整？不耽误您时间，谢谢老师。
```

### 场景10：老师否定选题 / 提出较大修改

- 第一步别急着辩解，先问清原因："老师，您主要担心的是创新性、可行性还是样本？我想把问题找准。"
- 带着老师的反馈回来，和 AI 一起评估：哪些必须改、有没有文献/数据能支撑原方案，再给老师一个调整后的方案。
- 回应模板："您说的这点我之前确实没考虑到。我按您的意见调整了一版【说明怎么调】，您看这样是否解决了您担心的问题？"

### 场景11：老师长时间不回复

- 先判断是否真的紧急；非紧急不要连环发。
- 隔 3–5 个工作日，用场景9的方式礼貌提醒一次，附上原消息和材料，方便老师直接看。
- 仍无回复且临近截止日期，可在工作时间电话或当面找，并同步给教务/辅导员留痕（只在确有必要时）。

### 场景12：和老师意见不一致

- 老师是第一责任人，涉及学术判断的分歧，先充分理解老师理由。
- 若你确有文献/方法依据，用"请教+证据"的方式表达，而不是反驳：
  "我看到【某文献/教材】是这样处理的【附上】，和您说的【】我有点没理清，想请您再指点一下，最终按您的意见定。"
- 充分沟通后仍以导师意见为准；保留你的依据记录即可。

## 四、邮件 / 微信基本礼仪

- **附件命名统一**：`姓名-论文题目-材料类型-版本-日期`，例如 `张三-AI情感依赖与NSSI-开题报告-第2版-20260920`。
- **邮件标题写清**：`【毕业论文】姓名+事项+版本`，方便老师检索。
- 一封邮件说清：我是谁、什么事、需要老师做什么、截止时间；附件在正文里点明。
- 尽量在工作时间发送（避免深夜、节假日催办）；提交后给老师合理的审阅时间。
- 老师的意见尽量当天回复"收到，我按此修改"，让对方知道你已接收。

---

## 五、怎么判断老师的态度（别过度解读）

- **回得短、只挑问题**：多数导师的常态，是在帮你避坑，不代表对你有意见。
- **让你"再看看/再想想"**：通常是方向或依据还不够，回去补文献、补方案，而不是等老师给答案。
- **明确说"可以/就这样做"**：尽快用文字确认一遍结论，再往下推进。
- **愿意给你介绍资源/帮你转发问卷**：说明认可你的进展，及时感谢并反馈结果。
- 拿不准态度时，直接、礼貌地问："老师，我想确认一下，这个方案现在是可以继续推进，还是需要再调整？"

## 六、沟通红线（不要做）

- 不临时抱佛脚、不长期失联后甩一份稿子要求老师马上看。
- 不把 AI 生成的内容不加核实直接发给老师（文献、数据、量表尤其要自己核实）。
- 不在被批评时顶撞、甩锅或敷衍说"知道了"却不改。
- 不伪造老师意见、不编造数据来迎合老师。
- 不在群里公开争论分歧；有分歧私下沟通。
- 不一个问题反复问同样的内容——问过的结论记进进度卡。

## 七、沟通记录（配合进度卡）

每次重要沟通后，在 `我的工作区/我的论文进度.md` 的"关键决策日志"记：

| 日期 | 沟通方式 | 老师的核心意见 | 我要做什么 / 截止 |
|---|---|---|---|
| | 当面/微信/邮件 | | |

这样换对话、换 AI 时，新的 AI 一看就知道老师定过什么，不会让你重复劳动或做出和老师意见冲突的东西。
