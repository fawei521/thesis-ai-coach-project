# 论文PDF结构化阅读分析指南

> AI帮学生批量阅读论文PDF，按IMRaD框架提取信息，生成对比矩阵和研究空白分析。
> 学生自己也要读，AI的提取是"地图"，不是"替身"——关键论文必须亲自读原文。
>
> **带教约定**：本文件只提供本主题的专业步骤；每轮对话仍按 `core/coaching-protocol.md` 走引导循环、反馈三段式与 P0/P1/P2 分级，鼓励按 `core/encouragement-guide.md`（默认标准档，学生说"关闭鼓励"即关）；属于正式阶段的，收尾过 `core/coach-rules.md` 第十一节三道闸。

## 一、AI阅读论文的正确方式

### AI能做的
- 读取PDF全文（学生上传或AI下载后）
- 按固定框架提取结构化信息
- 批量对比多篇论文
- 生成文献对比矩阵
- 梳理研究脉络、识别研究空白
- 把英文论文的方法和结果翻译成中文

### AI不能做的
- 不能在没读PDF全文时凭标题编造内容
- 不能编造统计数字、样本量、结论
- 提取的每个关键信息都要能在原文找到（标注页码/章节）
- 读不到全文时明确说明"只有摘要，以下基于摘要"

### 学生必须自己做的
- 核心的10-15篇重点文献亲自精读
- 判断AI提取的内容是否准确
- 形成自己对研究领域的理解和观点
- 论文综述正文自己写

## 二、单篇文献结构化提取模板（IMRaD）

AI每读一篇论文，输出以下结构化卡片：

```
═══════════════════════════════════════
文献编号：第X篇
标题：
作者：
年份：
期刊/来源：
DOI / 链接：
获取方式：全文 / 仅摘要
═══════════════════════════════════════

【Introduction 引言】
1. 研究问题：这篇论文要回答什么问题？
2. 研究背景：为什么这个问题重要？
3. 研究空白：作者指出前人研究缺了什么？
4. 研究假设/目的：

【Methods 方法】
5. 研究设计：横断问卷 / 纵向追踪 / 实验 / 元分析 / 质性
6. 研究对象：
   - 样本量 N =
   - 人群（大学生/中学生/临床/社区）
   - 年龄范围、性别比例
   - 取样方式、地区
7. 测量工具（重点）：
   - 自变量用什么量表（名称、题数、信度α）
   - 因变量用什么量表
   - 中介/调节变量用什么量表
8. 统计方法：相关/回归/中介(PROCESS模型几)/调节/网络分析/SEM
9. 软件：SPSS / R / Mplus / AMOS

【Results 结果】
10. 主要发现（列出关键路径系数和显著性）：
    - 直接效应：
    - 中介效应（Bootstrap CI）：
    - 其他关键结果：
11. 假设是否得到支持：

【Discussion 讨论】
12. 理论贡献：
13. 实践启示：
14. 作者承认的局限：
15. 未来研究方向：

【与本研究的关系】（AI结合学生选题判断）
16. 哪些发现支持我的假设：
17. 哪些发现与预期不一致：
18. 方法上可借鉴之处：
19. 量表是否可参考：
20. 这篇文献在我论文中的用途：
    （引言背景/方法依据/结果对比/讨论对照）
═══════════════════════════════════════
```

## 三、批量阅读工作流

### 第1步：学生提供PDF
- 把下载好的PDF放在 `我的工作区/01-文献PDF/` 目录
- 或把文件直接上传给AI
- 一次可以给多篇

### 第2步：AI逐篇提取
- AI对每篇PDF输出上面的结构化卡片
- 提取不到的信息标注"原文未提及"，不编造
- 英文文献关键术语保留英文原文

### 第3步：生成文献对比矩阵

AI把多篇文献横向整理成表：

| 编号 | 作者(年份) | 样本 | 自变量量表 | 中介变量 | 因变量量表 | 统计方法 | 核心发现 | 与我关系 |
|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | |
| 2 | | | | | | | | |

### 第4步：研究空白分析

AI基于全部文献回答：
1. **自变量研究现状**：有多少研究做过？用什么量表？发现了什么？
2. **因变量研究现状**：影响因素有哪些？哪些被反复验证？
3. **中介路径**：
   - 自变量→因变量，有人做过吗？
   - 自变量→中介1→因变量，有人做过吗？
   - 自变量→中介1→中介2→因变量（我的链式模型），有人做过吗？
4. **我的研究空白**：哪个具体的变量组合还没人做？
5. **创新性论证**：用一句话说清"我新在哪"

### 第5步：输出文献综述素材

AI按主题（不是按论文一篇篇罗列）整理素材：
- 主题1：自变量的概念和测量
- 主题2：因变量的现状和影响因素
- 主题3：中介变量1的理论和证据
- 主题4：中介变量2的理论和证据
- 主题5：变量间关系的研究证据
- 每个观点后标注来源文献编号，方便学生引用

注意：这是**素材和脉络**，综述正文学生自己写。

## 四、重点文献 vs 泛读文献

### 精读（10-15篇）
标准：
- 直接研究我的自变量或因变量
- 用了我想用的量表
- 用了我想用的统计方法（如同类链式中介）
- 近5年、高被引、核心期刊
处理：完整IMRaD卡片 + 学生亲自读原文

### 泛读（20-40篇）
标准：
- 相关但不直接（如其他类型的依赖、其他人群）
- 提供背景和理论依据
处理：简化卡片（研究问题、方法、核心发现、与我关系）

### 略读（其余）
标准：
- 边缘相关，只在引言引用一两句
处理：记录完整引用信息 + 一句话核心观点

## 五、识别高质量文献的标准

AI帮学生判断文献质量：

| 指标 | 高质量信号 | 需谨慎信号 |
|---|---|---|
| 期刊 | CSSCI/北大核心、SSCI/SCI | 普通学报、预印本 |
| 被引 | 高被引（领域经典） | 刚发表无被引（不一定差） |
| 样本 | 样本量大、抽样规范 | 样本极小、取样随意 |
| 量表 | 用成熟量表、报告信效度 | 自编量表无验证 |
| 方法 | 方法严谨、报告完整 | 方法描述不清、统计错误 |
| 结论 | 结论有数据支撑、承认局限 | 过度推论、因果措辞用于横断数据 |

## 六、常见问题

| 问题 | 处理 |
|---|---|
| PDF是扫描版无法提取文字 | AI尝试OCR；不行则学生手动读关键部分 |
| 只有摘要没有全文 | 明确标注"仅摘要"，只提取摘要中有的信息 |
| 英文读不懂 | AI翻译方法和结果部分，专业术语保留英文 |
| 文献之间结论矛盾 | 不回避，在对比矩阵标注，讨论样本/方法差异 |
| AI提取的数字可疑 | 学生对照原文表格核实，关键系数必须核对 |
| 找不到研究空白 | AI帮分析"变量组合""人群""方法"三个维度的新意 |
