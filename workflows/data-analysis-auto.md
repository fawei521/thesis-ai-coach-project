# 自动化数据分析工作流

> 从原始问卷数据到论文结果章节的完整流程。AI能自动做的自动做，需要图形界面的（中介）引导学生用JASP/SPSS。
> 数据必须真实，任何情况下不允许修改、伪造、选择性删除数据。

---

## 分析全流程总览

```
原始数据
  → 1. 数据清洗（data_cleaner.py，自动）
  → 2. 反向计分 + 算量表总分（auto_stats.py / Excel，自动）
  → 3. 信度分析（auto_stats.py / JASP，自动）
  → 4. 效度检验（JASP/SPSS，引导）
  → 5. 共同方法偏差（JASP/SPSS，引导）
  → 6. 描述统计（auto_stats.py，自动）
  → 7. 相关分析（auto_stats.py，自动）
  → 8. 核心分析：中介/链式中介（JASP/SPSS PROCESS，引导）
  → 9. 补充分析：网络分析（R，进阶可选）
  → 10. 生成图表（chart_generator.py，自动）
  → 11. 撰写结果（AI解读+学生写）
```

---

## 第1步：数据清洗（自动）

**工具**：`tools/data_cleaner.py`

AI告知学生后运行：
```
python tools/data_cleaner.py 原始数据.csv --min-seconds 30
```

自动检测：
- 答题时间过短（默认<30秒，可调）
- 连续10题以上选同一选项
- 所有题目答案完全相同

输出清洗后数据 + 无效问卷清单。

**人工补充判断标准**（AI提醒）：
- 测谎题/验证题作答矛盾
- 规律作答（如12345、54321循环）
- 逻辑矛盾（如选"从未使用AI"但AI依赖题全选高分）

---

## 第2步：反向计分与量表总分

### 反向计分
- Likert 5点量表：反向分 = 6 - 原始分
- Likert 4点量表：反向分 = 5 - 原始分
- Likert 7点量表：反向分 = 8 - 原始分
- 公式：反向分 = (最高分 + 1) - 原始分

AI根据量表原文确认哪些题是反向题，生成反向计分后的数据。

### 计算量表总分/均分
- **总分** = 该量表所有题目（反向计分后）相加
- **均分** = 总分 ÷ 题数（题数不同的量表间比较用均分）
- 缺失值处理：某题缺失，可用该量表均分替代（缺失<20%时）；缺失多则该问卷作废

**工具**：AI指导用auto_stats.py或Excel，生成含各量表总分的分析数据集。

---

## 第3步：信度分析（自动）

**工具**：`tools/auto_stats.py --scales scales.txt`

量表配置文件 scales.txt：
```
AI情感依赖=AI1,AI2,AI3,AI4,AI5
孤独感=ULS1,ULS2,ULS3,ULS4,ULS5,ULS6
反刍思维=RRS1,RRS2,...,RRS22
NSSI=NSSI1,...
```

输出每个量表的 Cronbach's α 和删题后α。

**判断标准**：
- α ≥ .90 优秀；.80-.89 良好；.70-.79 可接受；.60-.69 勉强（需说明）；<.60 不合格
- 删题后α明显升高（>0.02）且该题校正相关低，可考虑删题（要说明理由）

**论文表述**：见 psychology/stats-guide.md

---

## 第4步：效度检验（JASP/SPSS引导）

### 探索性因子分析EFA（本科常用）
- KMO > .70，Bartlett球形检验 p < .05
- 因子载荷 > .40
- AI给JASP/SPSS具体点击步骤

### 验证性因子分析CFA（进阶）
- 用AMOS/Mplus/R(lavaan)
- 拟合指标：χ²/df<3, RMSEA<.08, CFI/TLI>.90, SRMR<.08
- 本科论文引用原量表效度 + 报告本样本α通常也可接受

---

## 第5步：共同方法偏差（JASP/SPSS引导）

Harman单因子检验：
- 所有量表题目一起做未旋转因子分析
- 第一公因子解释率 < 40% 即不严重
- 超40%：讨论中说明局限，强调程序控制（匿名、反向计分、分开计分）

---

## 第6步：描述统计（自动）

**工具**：`auto_stats.py`

输出各变量 N、均值、标准差、最小值、最大值。
- 人口学变量报告频数和百分比
- AI生成表1（描述统计表）

---

## 第7步：相关分析（自动）

**工具**：`auto_stats.py`

输出量表总分间的Pearson相关矩阵（r + 显著性）。
- 相关方向要符合理论预期（为中介做前提检验）
- 中介前提：X与M相关、M与Y相关、X与Y相关
- AI生成表2（相关矩阵表）

---

## 第8步：核心分析——中介效应（JASP/SPSS引导）

这是论文核心，用成熟工具，AI给逐步操作：

### 简单中介：PROCESS模型4
### 链式中介：PROCESS模型6

**SPSS**：安装PROCESS宏（AI指导从hayesprocess.com免费下载安装）
**JASP**：菜单 Regression → Mediation（新版原生支持链式中介）

操作要点：
- Bootstrap 5000次，95%置信区间
- 置信区间不包含0 = 效应显著
- AI解释每条路径、直接/间接效应、完全/部分中介

**结果表格**：
- 表3：各路径回归系数（β、SE、t、p）
- 表4：中介效应分解（效应值、Boot SE、Boot CI上下限）

详细步骤见 psychology/stats-guide.md 第六、七节。

---

## 第9步：补充分析（进阶可选）

### 网络分析
- 适用：样本>250，想展示变量整体结构、找核心节点
- 工具：R（qgraph + bootnet，EBICglasso网络）
- AI给完整R代码和结果解读
- 定位：加分项，不是必须；样本不够不要硬做

### 调节/有调节中介
- PROCESS模型1（调节）、7/14/15（有调节中介）
- 按研究假设决定是否需要

---

## 第10步：生成图表（自动）

**工具**：`tools/chart_generator.py`

研究模型图（标注路径系数）：
```
python tools/chart_generator.py --variables "AI情感依赖,孤独感,反刍思维,NSSI" --coefs "a,b1,b2,c'" --type chain --output 模型图.png
```

图表规范：
- 三线表（AI生成CSV，学生复制到Word）
- 图分辨率300dpi
- 黑白可读，显著性用星号标注
- 表题在表上方，图题在图下方

---

## 第11步：结果解读与写作

AI对每个结果：
1. 解释数字含义（这个系数说明什么）
2. 判断是否支持假设
3. 给规范的论文表述模板
4. 结果不符合预期时，帮分析原因（不改数据）

学生自己把结果写成正文，AI只改语言和逻辑。

## 分析结果检查清单（质量闸）

- [ ] 有效样本量达到要求（链式中介建议≥200，至少>150）
- [ ] 所有量表α达标或已说明
- [ ] 共同方法偏差已检验
- [ ] 描述统计、相关分析完整
- [ ] 中介效应Bootstrap CI报告完整
- [ ] 图表数字与正文一致
- [ ] 所有假设都有"支持/不支持"的明确结论
- [ ] 不显著的结果如实报告
- [ ] 表格是三线表、图300dpi
- [ ] 统计数字可复现（保留原始数据和分析记录）

## 常见问题

| 问题 | 处理 |
|---|---|
| 样本量不够 | 见coach-rules错误处理；链式可降级为简单中介；绝不编数据 |
| α低 | 查反向计分、删低质量题、必要时换量表 |
| 相关不显著 | 中介可能不成立，如实报告，讨论原因 |
| 中介CI包含0 | 中介不成立，报告为"中介效应不显著"，讨论理论原因 |
| 不会装PROCESS | 用JASP原生中介功能，或让AI开虚拟电脑指导 |
| auto_stats结果和SPSS略有差异 | 以SPSS/JASP为准，脚本用于快速预览 |
| 结果和假设相反 | 不显著/反向也是发现，诚实讨论，可能是创新点 |
