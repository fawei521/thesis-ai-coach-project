# 自动化数据分析工作流

> 从原始问卷数据到论文结果章节的完整流程。AI能自动做的自动做，需要图形界面的（中介）引导学生用JASP/SPSS。
> 数据必须真实，任何情况下不允许修改、伪造、选择性删除数据。
>
> **带教约定**：本文件只提供本主题的专业步骤；每轮对话仍按 `core/coaching-protocol.md` 走引导循环、反馈三段式与 P0/P1/P2 分级，鼓励按 `core/encouragement-guide.md`（默认标准档，学生说"关闭鼓励"即关）；属于正式阶段的，收尾过 `core/coach-rules.md` 第十一节三道闸。

---

## 分析全流程总览

```
问卷星原始导出
  → 外发前隐私闸：去标识化（anonymize_data.py，菜单第11项；要把数据发给AI/上传/给外校前先做，纯本地分析可跳过）
  → 0. 预处理（wjx_preprocess.py，自动：中文表头/文本选项/"2分3秒"用时 → 标准数字表 + 列映射报告）
原始数据
  → 1. 数据清洗（data_cleaner.py，自动）
  → 2. 写 scales.txt（标量表归属和反向题），auto_stats.py 一条命令自动完成：
        反向计分 → 3.信度α → 4.效度(KMO/Bartlett/载荷) → 5.Harman共同方法偏差 → 量表总分
        → 6.描述统计 → 7.相关分析 → 初步回归，并导出三线表和"_量表总分.csv"
  → 4. 效度检验（脚本自动出KMO/Bartlett/载荷；自编多维量表加 --efa 做完整探索性因子分析；CFA引导JASP）
  → 8. 核心分析：中介/链式中介（auto_stats --mediators 自动出Bootstrap结果，再用JASP/SPSS PROCESS复核）
  → 9. 补充分析：网络分析（R，进阶可选）
  → 10. 生成图表（chart_generator.py，自动）
  → 11. 撰写结果（AI解读+学生写）
```

## 外发前隐私闸：数据去标识化（强烈建议，自动）

> 只要数据要**发给 AI、上传网盘/平台、或给外校/第三方**，先做这一步；全程只在自己电脑本地跑分析、不外发时可跳过。
> 问卷星预处理只会丢掉它认识的平台元数据列（IP、提交时间、微信昵称等）；同学为抽奖/课程学分/前后测配对而**自己加的姓名、学号、手机、邮箱等列会原样保留**，必须靠本步处理。

**工具**：`tools/anonymize_data.py`（菜单第11项）
```
python tools/anonymize_data.py 问卷星原始.csv            # 自动识别并另存去标识化文件
python tools/anonymize_data.py 问卷星原始.csv --dry-run  # 先只体检、不写文件
```
- 自动**假名化**（第一个身份列如姓名/学号 → 与个人信息无关的编号 P001…）或**删除**直接标识符：姓名、学号、手机、邮箱、身份证、微信/QQ、IP、详细住址、出生日期等；表头没写明的，也会按手机号/邮箱/身份证等**内容模式**识别。
- 对性别、年级、专业、生源等**准标识符**做 **k-匿名体检**（默认 k=3）：这些列分析要用、默认保留，只提示哪些稀有组合可能被"对号入座"及合并类别等补救办法。
- **只读原文件、另存为新文件，绝不改动原始数据**；生成 `_去标识化.csv`、`_去标识化报告.txt`；需要前后测配对时另生成 `_假名对照表.csv`。
- ⚠ **假名对照表是唯一能把编号还原到个人的钥匙**：必须与数据分开、离线单独保管，绝不随数据发给 AI/上传，配对完成后尽早删除；加 `--no-key` 则彻底不留、不可复原（更接近《个人信息保护法》第七十三条的"匿名化"，保留对照表时仅为"去标识化"）。
- 去标识化不免除知情同意、伦理审查与数据保管义务（见 `psychology/ethics.md`）。

## 第0步：问卷星原始数据预处理（自动）

> 如果数据本来就是"列名Q1-Qn、答案全是数字"的干净CSV，可跳过本步直接到第1步。

问卷星导出的原始表通常含元数据列、中文题目表头、文本选项（"非常同意"）、"2分3秒"格式用时，
无法直接统计。先用预处理工具转换：

**工具**：`tools/wjx_preprocess.py`（菜单第1项）
```
python tools/wjx_preprocess.py 问卷星原始.csv
```

自动完成：识别编码、跳过元数据列、用时统一成秒、Likert文本选项转1-5数字、题目重命名为Q1,Q2…
同时生成《列映射报告》。

**必须人工核对**：
- 打开列映射报告，确认"非常不同意=1、非常同意=5"方向无误
- 性别等人口学列保留文字（做频数统计）；年级等有序分类若需转数字，按报告提示人工处理
- 抽查3-5份原始答卷与转换结果一致
- 反向题不在此步处理，留到第2步

**多选题与开放填空题（报告第四节，重要）**：
- 多选题（问卷星默认一列、选项间用 `┋` 分隔；或导出时"按选项拆分"成多个 0/1 列）和开放填空题**不是 Likert 量表题**，预处理会保留原文并在报告中单独列出，**写 scales.txt 时绝不能把它们列入量表**，否则信度α和量表总分会错。
- 多选题：直接用问卷星后台的各选项选择人数/百分比做描述统计；要做交叉分析就导出"按选项拆分"的 0/1 列，清洗器会自动识别并排除，不计入长直线/低变异等质量指标。
- 开放填空题：做归类、词频或引用典型回答，不参与数值统计。
- 真正需要编码的固定选项单选题（如年级措辞无法识别）在报告第五节，按提示在问卷星选"按选项序号下载"或人工编码。

## 第1步：数据清洗（自动）

**工具**：`tools/data_cleaner.py`

AI告知学生后运行（建议提供 scales.txt，质量判断只针对量表题、更准）：
```
python tools/data_cleaner.py 原始数据.csv --scales scales.txt \
  --attention "本题请选3=3;认真作答请选2=2"
```
- `--attention "列名关键词=正确答案;..."`：问卷里放的**注意力检查题（instructed response item）**，多道用分号隔开，答错即判无效（最受审稿认可的硬指标，建议正式问卷放1–2道）
- `--min-seconds 30`：最短答题时长（默认30秒）
- `--longstring 10`：连续多少题选同一项判长直线（默认10）
- `--low-sd 0.3`：个体作答SD低于该值判"几乎无变异"（默认0.3，设0关闭）
- `--max-missing 0.2`：作答缺失率超过该比例判无效（默认0.2即两成）

自动检测（只对量表/Likert作答题计算，自动排除时长、序号、性别年级等人口学列）：
- 答题时间过短
- 长直线作答 straight-lining（连续多题选同一项）
- 作答几乎无变异（个体内SD过低，比"全同"更敏感）
- 作答缺失率过高
- 注意力检查题答错

输出：清洗后数据 `*_cleaned.csv` ＋ **剔除明细报告 `*_清洗报告.csv`**（每份被剔除问卷的行号、时长、最长连续相同、SD、缺失率、原因），并按原因汇总份数，直接支撑论文"数据清洗"部分写明剔除标准与份数。

**仍需人工/设计阶段把控**（脚本不硬判，避免误删真实作答）：
- 规律作答（如12345、54321循环）：可结合注意力题与长直线综合判断
- 逻辑矛盾（如选"从未使用AI"但AI依赖题全选高分）：属于内容/测谎设计，在问卷里用跳题或验证题前置控制
- 剔除标准一经确定要在开题/方法里写明，**不得为追求显著而临时放宽或加严**

## 第2步：反向计分与量表总分（自动）

### 2.0 怎么知道哪个 Q 属于哪个量表、哪题是反向题（关键，别跳过）
预处理后题目被重命名成 Q1、Q2…，需要你对照两份东西写配置：
1. 打开第0步生成的**《列映射报告》**，里面写了 Q1 对应你问卷里的哪一道原题；
2. 对照**问卷设计时的量表顺序**（例如第1-5题是AI情感依赖、第6-9题是孤独感……）；
3. 对照**量表原文/计分说明**逐题确认反向题（反向题通常表述方向与其他题相反，
   如孤独量表里"我常感到有人可以倾诉"这类正向题混在一堆负向题中）。
拿不准就把量表原文发给AI，让AI帮你逐题标，但**你要对照原文复核**，标反一题α和总分全错。

### 2.1 写量表配置文件 scales.txt
格式（每行一个量表，反向题在题目后加 `(R)`，量表名后用 `:点数` 指定点数，默认5点）：
```
AI情感依赖:5=X1,X2(R),X3,X4(R),X5
孤独感:5=M1,M2,M3,M4
NSSI:5=Y1,Y2,Y3(R),Y4,Y5
```
- 反向题一定要从量表原文核对清楚，标错会让α和总分全错
- 4点量表写 `:4`，7点写 `:7`

### 2.2 一条命令完成反向计分+信度+量表总分
**工具**：`tools/auto_stats.py --scales scales.txt`（菜单第3项）

它会自动：
1. 对 `(R)` 题目反向计分（5点：6−原值；4点：5−原值）
2. 用**反向计分后**的题目算 Cronbach's α（含反向题却不反转，α会严重偏低甚至为负）
3. 计算每个量表的总分和均分，导出 `_量表总分.csv`（保留原始所有列）
4. 在量表总分层面做描述统计、相关、回归

**关键**：之后JASP/SPSS/PROCESS做中介，直接打开 `_量表总分.csv`，用各量表"总分"列。

### 2.3 手动核对（可选）
- 反向计分公式：反向分 =（最高分+1）− 原始分
- 缺失值：某题缺失且该量表缺失<20%，可用该量表均分替代；缺失多则该问卷作废
- 抽查2-3份，确认总分=反向计分后各题之和

## 第3步：信度分析（自动，已含在第2步）

**工具**：`auto_stats.py --scales scales.txt`

输出每个量表的 Cronbach's α、逐题 **CITC（校正项总相关）** 与删题后α（反向题已正确处理），自动标记 CITC<.40 或删题后α升高的题，并导出"数据名_题项分析.csv"（可直接整理成信度三线表）。

**判断标准**：
- α ≥ .90 优秀；.80-.89 良好；.70-.79 可接受；.60-.69 勉强（需说明）；<.60 不合格
- **α出现负值或异常低，先检查是不是反向题没标/标错**（这是最常见原因）
- **CITC ≥ .50 良好、.40–.50 可接受、<.40 需排查**；删题后α明显升高（>0.02）且 CITC 低，可结合理论考虑删题（要说明理由，删后重算α与因子结构）
- CITC 与删题α已用 Wolfram 对小样本整数数据黄金验证，逐位一致
- **分半信度（自动）**：每个量表同时报前后半（SPSS口径）两半α、两半相关 r、**Spearman-Brown=2r/(1+r)**、**Guttman λ4**；奇数题另报奇偶分半（两半等长）；导出"数据名_信度分析.csv"（α/两半α/SB/λ4，与 numpy 逐位一致）。α 与分半都高才说明单维一致性稳健，分半明显低于 α 时先查因子结构

**论文表述**：见 psychology/stats-guide.md

**预试项目分析（自编/修订量表必做，菜单第 14 项 `item_analysis.py`）**：第2步的 CITC/删题α是对正式数据的信度检查；若你在**预试**阶段要按教材做完整项目分析（决断值 CR 法），用该工具吃预试数据与同一份 `scales.txt`，它按量表总分取高/低各 27%，逐题给独立样本 t（决断值 CR，**|CR|≥3 且 p<.05** 为区分度合格）、均值标准差、CITC、删题后α与"保留/建议讨论删改"，导出"数据名_项目分析.csv"。CR 不显著、CITC<.40、删题后α明显升高只提示讨论，**删题必须结合内容效度与专业理论，并在删后重算α与因子结构；正式数据不要反复套用预试删题标准**。

## 第4步：效度检验（脚本自动 + JASP/SPSS补充）

### 4.1 单维量表结构效度（自动，已含在第2步）
`auto_stats.py --scales scales.txt` 对**每个量表内部题目**（反向计分后）自动输出：
- **KMO抽样适合度**：>.9极佳，>.8适合，>.7可接受，<.6不适合因子分析
- **Bartlett球形检验**：χ²(df)，需 p<.05（脚本自动给p值）
- **第一主成分**：特征值、方差解释率（单维量表建议>50%~60%）、各题因子载荷（应>.5，<.5会标出）

引用/改编成熟单维量表时，报告 KMO、Bartlett显著、各题载荷>.5、第一因子解释率即可，脚本一次出齐。

### 4.2 多维/自编量表（脚本可做EFA + JASP/SPSS补充CFA）
**探索性因子分析EFA（脚本已支持，一键）：**
```
# 对全部量表做完整EFA（主成分提取＋特征值≥1定因子数＋Varimax最大方差旋转）
python tools/auto_stats.py 数据.csv --scales scales.txt --efa
# 只对自编/修订的某几个量表做（空格或逗号分隔）
python tools/auto_stats.py 数据.csv --scales scales.txt --efa 我的新量表,修订量表
```
输出 KMO、Bartlett、全部特征值、因子数、**Horn 平行分析（默认500次随机模拟，给随机特征值均值/95%分位与建议因子数，`--pa-rep 0` 可关闭）**、旋转后载荷矩阵、共同度、交叉载荷/低载荷标记、累计方差解释率，导出"数据名_因子分析.csv"，并为每个量表导出"数据名_量表名_碎石图.png"（300dpi，含λ=1线、平行分析随机均值/95%线与保留因子高亮，可直接插图）。判定：KMO>.7（>.6可接受）、Bartlett p<.05、载荷>.40（>.50理想）、交叉载荷（两个因子都≥.40且差<.20）考虑删题、累计方差≥50%~60%；**因子数综合特征值≥1、碎石拐点、平行分析、理论四者，优先平行分析＋理论**。算法（Jacobi谱分解＋Kaiser归一化Varimax＋Horn平行分析）已用 Wolfram 独立黄金验证，2/3因子构造数据均能正确还原结构，纯随机数据不误判因子。

**脚本做不到、需 JASP/SPSS 的部分：** 手动固定因子数、Promax斜交旋转（因子相关时）、因子相关矩阵。JASP：Factor → Exploratory Factor Analysis。

**验证性因子分析CFA（进阶，需专门软件）：** AMOS/Mplus/R(lavaan) 或 JASP Factor → CFA，报告 χ²/df<3、RMSEA<.08、CFI/TLI>.90、SRMR<.08。脚本不做SEM，AI给具体点击步骤或 lavaan 代码。

**聚合效度/区分效度（CFA 之后，菜单第 13 项 `validity_cr_ave.py` 一键算）：** 拿到 CFA 的**标准化因子载荷**后，用它算每个因子的组合信度 CR、平均方差抽取 AVE、√AVE，并结合因子间相关做 Fornell-Larcker 区分效度判定（CR≥.70、AVE≥.50 为常用门槛，.36–.50 且 CR 良好时可接受需说明；√AVE 应大于该因子与其它因子的 |r|）。题项少可直接 `--factor "名称=载荷,..."`，题项多用 `--loadings-csv 载荷表.csv --corr-csv 因子相关.csv`，可 `--csv-out` 另存 `_聚合区分效度.csv`。区分效度建议同时在 CFA 软件里补报更现代的 HTMT（<.85/.90）。载荷必须来自真实测量模型输出，不得为达标手改。

> 多数本科问卷研究引用成熟量表，4.1的自动结果 + 报告原量表效度通常已够；**自编或重大修订的多维量表**才需要 4.2 的完整 EFA（脚本一键出结果，JASP补碎石图/斜交）。

## 第5步：共同方法偏差（自动，已含在第2步）

**工具**：`auto_stats.py --scales scales.txt`（自动执行Harman单因子检验）

Harman单因子检验：
- 所有量表题目（反向题先反向计分）一起做未旋转主成分分析
- 工具自动报告第一公因子方差解释率
- 第一公因子解释率 < 40% 即不严重（工具会直接给结论和论文表述模板）
- 超40%：讨论中说明局限，强调程序控制（匿名、反向计分、分开计分），必要时用JASP复核

> 说明：脚本用幂迭代求相关矩阵第一主成分，结果与SPSS/JASP的未旋转因子分析第一因子一致；
> 如需完整的多因子方差解释表，再用JASP Factor → Principal Components 复核。

## 第6步：描述统计与研究对象（自动，已含在第2步）

**工具**：`auto_stats.py --scales scales.txt`

- 各量表总分的 N、均值、标准差、最小值、最大值，以及**偏度/峰度与正态性判读**（Kline：|偏度|<3、|峰度|<10 即可，明显偏态用 Bootstrap 而非硬转正态），随 `_统计结果.csv` 导出
- `_统计结果.csv` 的**表2**直接给出论文标准"描述统计与相关矩阵"：均值M、标准差SD、下三角 Pearson 相关（带 */**/*** 星号）、对角为各量表 Cronbach's α，复制到 Word 稍作排版即是表1
- **研究对象/样本构成（自动）**：脚本自动识别人口学分类列（量表题目之外、取值种类少的列，兼容"男/女"文本和1/2编码），输出性别、年级、生源地、是否独生子女等的**频数与百分比**，并导出 `_频数表.csv`，直接用于论文"研究对象"部分
  - 数值编码列按取值≤4类识别（覆盖性别1/2、年级1-4、是否1/2，自动排除5/7点量表题）；文本列按≤10类识别
  - 若某人口学列没被识别（如专业类别很多），可在Excel里补做频数表，或让AI帮你核对列名
- **人口学交叉（自动）**：脚本同时对识别到的人口学分类列**两两做卡方独立性检验**（分类×分类，如性别×年级、性别×是否独生），报 χ²(df)/p/Cramér's V（.1/.3/.5 小中大），导出 `_卡方检验.csv`；2×2 自动 Yates 校正，期望频数<5 时提示改用 Fisher 精确检验（JASP/SPSS）。常用于报告"样本在各年级的性别构成是否均衡"

## 第7步：相关分析（自动，已含在第2步）

**工具**：`auto_stats.py --scales scales.txt`

自动输出量表总分间的 Pearson 相关矩阵（整合在 `_统计结果.csv` 表2，含 r、显著性星号与对角 α；表3 给出每对变量的双尾 p 与成对 N）。
- 同时自动导出"数据名_相关热图.png"：下三角相关系数＋显著性星号、对角 Cronbach α、上三角留白，可直接插结果部分或答辩 PPT（`--spearman` 时为秩相关热图；未装 matplotlib 时自动跳过，不影响数值）
- 相关方向要符合理论预期（为中介做前提检验）
- 中介前提：X与M相关、M与Y相关、X与Y相关
- 也可加 `--y 因变量量表名 --x "X量表名,M量表名"` 先跑一个初步回归看路径
- 多元回归自动报**共线性诊断（容差/VIF）**：VIF<5 正常、5–10 关注、≥10 严重（需删并变量）；中介把 X 与各 M 同时放入时务必先看 VIF，避免系数符号反常
- **多元异常值（回归/中介假设检查）**：加 `--mahalanobis`（不带变量=对全部量表总分，也可 `--mahalanobis X总分,Y总分` 指定），按马氏距离 D² 与 χ² 判据（默认 p<.001）只**标记**多元异常个案并导出 `_多元异常值.csv`。多元异常值≠无效问卷，**不自动删除、不为好看删点**；回查原始作答后做敏感性分析（剔除/保留各跑一次，结论稳定就保留并说明，翻转则与导师讨论）。详见 `psychology/stats-guide.md` 第六节前置。
- 变量明显偏态/有序等级（如 NSSI、成瘾）时加 `--spearman`，相关节改报 Spearman 秩相关（与 scipy 一致），整合表仍报 Pearson，可并列附录
- 需要排除性别/年级等混淆看净相关时加 `--partial "性别,年级"`，输出偏相关矩阵与 `_偏相关.csv`（df=n−2−控制变量数，与回归残差法逐位一致）；控制后由显著变不显著要如实写

### 7.1 人口学差异分析（自动，已含在第2步）

脚本自动识别人口学分组列（性别/是否独生子女等二分类，年级/生源地等 3–4 类，兼容"男/女"文本），对每个量表总分：
- **2 组 → 独立样本 t 检验**：报 t(df)、p、Cohen's d（.2/.5/.8 小中大效应）
- **3 组及以上 → 单因素 ANOVA**：报 F(dfb,dfw)、p、η²（.01/.06/.14 小中大），并给 Bonferroni 校正事后两两比较
- 导出 `_差异分析.csv`，可直接整理成"人口学差异分析表"
- 脚本先做 Levene/Brown-Forsythe 方差齐性检验：方差齐用等方差 t/ANOVA（Bonferroni事后），**不齐自动切换 Welch t / Welch ANOVA**（多组事后改 Games-Howell，在 JASP/SPSS 查看）；`_差异分析.csv` 含方差齐性与 Welch 稳健检验列；正式结果可在 SPSS/JASP 复核
- **因变量明显偏态/有序等级（如 NSSI、成瘾、频次零膨胀）、正态前提不满足时**：加 `--nonparametric`（菜单第3项选"是"），2组改 **Mann-Whitney U**（报 U/z/p/r），多组改 **Kruskal-Wallis H**（报 H/df/p/ε²，事后用 Dunn，JASP查看），导出 `_差异分析_非参数.csv`；与 scipy 逐位一致。是否需要非参数，先看第4步描述统计的偏度/峰度（|偏度|>3、|峰度|>10 为明显违反）

## 第8步：核心分析——中介效应（脚本自动 + JASP/SPSS复核）

### 8.1 先用脚本一键出结果（自动）
**工具**：`auto_stats.py --mediators`（菜单第3项，会依次问你因变量、自变量、中介）

- 简单中介（模型4），1个中介：
```
python tools/auto_stats.py 数据_量表总分.csv --scales scales.txt \
  --y NSSI --x AI情感依赖 --mediators 孤独感 --boot 5000
```
- 链式中介（模型6），2个中介（按路径顺序，逗号分隔）：
```
python tools/auto_stats.py 数据_量表总分.csv --scales scales.txt \
  --y NSSI --x AI情感依赖 --mediators "孤独感,反刍思维" --boot 5000
```

脚本自动输出（并导出 `_中介效应.csv`）：
- 各路径系数（未标准化B和标准化β：a、b、c、c'，链式含d21）
- 各条间接效应、Boot SE、95%CI（Bootstrap默认5000次，百分位法，固定种子可复现）
- **CI不含0即该效应显著**；自动判断完全/部分中介、链式路径是否成立
- 自检恒等式：总效应 c = 直接效应 c' + 间接效应合计

### 8.2 再用JASP/SPSS复核（正式结果）
脚本用于快速预览和练手；**写进论文的正式结果建议用成熟工具复核一遍**（导师更认可）。
**数据打开第2步导出的 `_量表总分.csv`，变量选各量表"总分"列。**

**SPSS**：安装PROCESS宏（AI指导从processmacro.org免费下载安装），简单中介选模型4、链式选模型6
**JASP**：简单中介用 Regression → Mediation（勾Bootstrap）；**链式中介（模型6，M1→M2有序）需在顶部模块库(+)安装官方 Process 模块后选 Model 6（JASP 0.18.2 及以后——官方 Process 模块自 0.18.2 起随版本发布），或用 SEM 模块(lavaan)**；原生 Mediation 主要支持简单/并行中介，不直接做有序链式

复核要点：
- Bootstrap 5000次，95%置信区间；建议同时看偏差校正(bias-corrected)CI
- 置信区间不包含0 = 效应显著
- AI解释每条路径、直接/间接效应、完全/部分中介；脚本与JASP结论应一致，不一致以JASP为准并排查

**结果表格**：
- 表3：各路径回归系数（β、SE、t、p）
- 表4：中介效应分解（效应值、Boot SE、Boot CI上下限）

详细步骤见 psychology/stats-guide.md 第六、七节。

## 常见问题

| 问题 | 处理 |
|---|---|
| 样本量不够 | 见coach-rules错误处理；链式可降级为简单中介；绝不编数据 |
| α低 | 查反向计分、删低质量题、必要时换量表 |
| 相关不显著 | 中介可能不成立，如实报告，讨论原因 |
| 中介CI包含0 | 中介不成立，报告为"中介效应不显著"，讨论理论原因 |
| 不会装PROCESS | 简单中介用JASP的 Regression → Mediation；链式中介在JASP模块库(+)装官方 Process 模块选 Model 6，或让AI开虚拟电脑一步步指导 |
| auto_stats结果和SPSS略有差异 | 以SPSS/JASP为准，脚本用于快速预览 |
| 结果和假设相反 | 不显著/反向也是发现，诚实讨论，可能是创新点 |
