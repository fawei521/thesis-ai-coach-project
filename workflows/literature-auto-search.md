# 文献自动检索工作流

> AI通过虚拟电脑（浏览器自动化）和学术API，帮学生完成文献检索、收集和初步分析。
> 学生只需要登录一次，后续搜索、翻页、收集题录由AI自动完成。

---

## 一、AI能力说明

AI具备**虚拟电脑/浏览器自动化**能力，可以：
- 打开和操作网页（点击、输入、翻页、截图）
- 读取网页内容（标题、作者、摘要、期刊信息）
- 下载文件（PDF）
- 遇到登录、验证码时暂停，请学生接管操作

AI**不会**：
- 存储或自动输入学生的账号密码
- 绕过付费墙或验证码
- 在学生未授权的情况下操作

## 二、知网检索流程（中文文献）

### 第1步：打开学校图书馆（学生操作登录）

**九江学院默认路径（示例，其他学校替换）：**

1. AI打开浏览器，访问学校图书馆官网
   - 九江学院：`https://lib.jju.edu.cn`
2. AI点击"文献资源"或"电子资源"
3. AI找到"OA资源"或"数据库导航"
4. AI在数据库列表中找到"中国知网（CNKI）"
5. AI点击知网访问入口，跳转到知网页面

**登录环节（必须学生自己操作）：**
- 如果需要统一身份认证（学号+密码），AI暂停，提示学生：
  > "现在需要登录学校账号，请你在浏览器里输入学号和密码完成登录。登录成功后告诉我，我继续操作。"
- AI不看、不记、不输入密码
- 学生登录完成后交回控制权

**其他学校学生：**
- 告诉AI你的学校名称和图书馆网址
- AI会找到对应学校的知网入口路径
- 如果找不到，学生可以自己先打开知网，再让AI接手

### 第2步：AI自动检索

登录成功后，AI按以下流程操作：

1. **确认检索关键词**
   - AI根据选题生成中英文关键词组（10-15个）
   - 跟学生确认后开始检索

2. **逐组关键词搜索**
   - AI在知网搜索框输入关键词
   - 选择"主题"或"篇名"检索
   - 设置筛选条件：核心期刊/CSSCI（可选）、近5-10年、学位论文/期刊论文

3. **自动翻页收集**
   - AI读取搜索结果列表
   - 对每篇文献提取：标题、作者、年份、期刊、被引次数
   - 自动翻页（通常收集前3-5页，约30-60条）
   - 重复不同关键词组的检索

4. **初步筛选**
   - AI根据标题和摘要判断相关性
   - 标记为：高相关/中相关/低相关
   - 高相关的标记为"建议精读"

### 第3步：下载重点文献

- AI对高相关文献点击进入详情页
- 如果学校已购买权限，AI点击下载PDF
- 下载到学生项目文件夹的 `文献PDF/` 目录
- 如果没有PDF权限，记录文献信息，建议学生通过馆际互借获取

### 第4步：导出题录

- AI在知网勾选收集的文献
- 点击"导出参考文献"
- 选择GB/T 7714格式或RIS格式
- 保存到项目文件夹

### 第5步：整理输出

AI产出：
1. **文献总表**（CSV）：序号、标题、作者、年份、期刊、关键词、相关性评级
2. **重点文献清单**：10-15篇建议精读的文献，附推荐理由
3. **研究空白总结**：基于检索结果，现有研究做了什么、没做什么
4. **下载的PDF文件**（如果有权限）

## 三、英文数据库检索（API自动检索）

英文文献通过免费学术API自动检索，不需要浏览器操作。

### 使用工具
运行 `tools/paper_search.py`，支持：
- **OpenAlex**（免费，无需API key，2.4亿篇文献，推荐首选）
- **Semantic Scholar**（免费，有引用数据和TLDR摘要）

### 检索流程
1. AI把中文关键词翻译成英文检索词
2. 运行脚本，例如：
   ```
   python tools/paper_search.py --source openalex --query "AI emotional dependence adolescent NSSI" --limit 20
   ```
3. 脚本自动检索并返回：标题、作者、年份、期刊、DOI、摘要、被引次数
4. AI筛选高相关文献，整理成表
5. 开放获取的文献，AI可以给下载链接

### 优势
- 不需要登录
- 不需要API key
- 几秒钟返回结果
- 可以按被引次数排序，快速找到高影响力文献

## 四、PDF自动阅读与结构化分析

### 工作流程

学生下载PDF后（或AI帮下载后），AI逐篇阅读并按IMRaD框架提取：

### 结构化提取模板

对每篇精读文献，AI输出以下信息：

```
【文献编号】第X篇
【标题】
【作者】
【年份】
【期刊】
【DOI】

1. 研究问题
   - 这篇论文想解决什么问题？
   - 研究空白是什么？

2. 研究设计
   - 研究类型：横断问卷/纵向追踪/实验/元分析/质性
   - 样本：N=？，什么人群（大学生/青少年/临床），年龄范围
   - 取样方式：方便取样/分层抽样/其他

3. 测量工具
   - 用了哪些量表（名称、题数、信度）
   - 关键变量怎么操作化定义的

4. 统计方法
   - 用了什么分析方法（相关/回归/中介/调节/网络分析/SEM）
   - 用了什么软件

5. 主要发现
   - 核心结果是什么（列出关键系数和显著性）
   - 假设是否得到支持

6. 理论贡献
   - 对理论有什么推进

7. 局限与未来方向
   - 作者自己说的局限
   - AI判断的局限

8. 与本研究的关系
   - 哪些发现支持我的假设
   - 哪些发现跟我的预期不一致
   - 方法上有什么可以借鉴
   - 量表是否可以参考
```

### 批量分析

- AI可以批量阅读多篇PDF
- 产出**文献对比矩阵**：横向对比各研究的样本、方法、发现
- 产出**研究空白图**：哪些变量关系已经被验证、哪些还没有

### 文献综述初稿辅助

AI基于结构化分析，帮学生梳理：
- 自变量的研究脉络
- 因变量的影响因素
- 中介变量的理论依据
- 现有研究的不足（即本研究的切入点）

注意：AI只帮梳理脉络和素材，文献综述正文必须学生自己写。

## 五、安全与伦理

1. **账号安全**：密码由学生自己输入，AI不接触
2. **版权合规**：只下载学校已购买权限的文献，不绕过付费墙
3. **验证码**：遇到验证码AI暂停，学生手动完成
4. **频率控制**：自动检索时控制速度，不对服务器造成压力
5. **数据真实**：所有文献信息来自数据库，AI不编造
6. **引用核实**：AI提取的信息需学生对照原文核实，特别是统计数据

## 六、常见问题

| 问题 | 处理方式 |
|---|---|
| 知网登录过期 | AI提示学生重新登录 |
| 搜索结果太少 | AI调整关键词，换同义词或放宽条件 |
| 搜索结果太多 | AI加筛选条件（核心期刊、近5年、篇名检索） |
| PDF下载失败 | 记录文献信息，建议学生手动下载或馆际互借 |
| API检索无结果 | 换OpenAlex/Semantic Scholar，或简化关键词 |
| PDF是扫描版 | AI尝试OCR识别，识别不了则提示学生手动阅读 |
| 学校没有知网权限 | 用万方、维普替代，或用Google Scholar找开放获取版 |
