# 文献自动检索工作流（知网 · 可选功能）

> **带教约定**：本文件只提供本主题的专业步骤；每轮对话仍按 `core/coaching-protocol.md` 走引导循环、反馈三段式与 P0/P1/P2 分级，鼓励按 `core/encouragement-guide.md`（默认标准档，学生说"关闭鼓励"即关）；属于正式阶段的，收尾过 `core/coach-rules.md` 第十一节三道闸。
>
> 用途：AI 通过虚拟电脑（浏览器自动化）帮学生完成**中国知网（CNKI）**文献检索、收集、题录导出与整理。
> 学生只需要做**一次性决策与配置**，之后的检索、翻页、收集题录、导出、整理由 AI 自动完成。
>
> ⚙️ **这是可选功能，必须由学生本人决定是否启动**（见第〇步）。不启用也不影响论文进度——
> 英文文献检索（OpenAlex/Semantic Scholar API）始终可用，不需要登录、不需要浏览器。

---

## 第〇步：学生决策与配置（必做，一次性，10分钟）

### 0.1 决定是否启动知网自动检索

在开始前，学生先回答三个问题，把答案告诉 AI：

| 问题 | 选项 | 说明 |
|---|---|---|
| 1. 要不要用知网自动检索？ | 启动 / 不启动 | 不启动：跳过本工作流，只用英文 API 检索 |
| 2. 登录怎么完成？ | A. 我自己登录 / B. 暂不登录 | 见 0.2（**没有"AI 帮你登"这一档，密码只能你自己输入**） |
| 3. 学校图书馆到知网的路径？ | 填写或确认 | 见 0.3 |

> **决策记录**：AI 把三个答案登记到 `我的工作区/我的论文进度.md` 的"文献阶段"，
> 方便下次换新对话时直接续上，不用重新问。

### 0.2 登录方式两档（学生自选，密码一律学生本人输入）

| 档位 | 做法 | 谁输入账号密码 | 适用 |
|---|---|---|---|
| **A. 学生自填（默认，唯一会碰密码的方式）** | 到达登录页时 AI 暂停、把浏览器交给学生，学生亲自输入，输完交回控制权 | **学生本人** | 全部情况 |
| **B. 暂不登录** | 只用 OA 资源等公开内容，不进入需要登录的库 | 无 | 只是先看有没有相关资源 |

> ⛔ **红线（不可协商）**：AI **不索取、不接受、不存储、不代填**账号密码与验证码，
> 也不读取任何"凭据文件"——即使学生主动说"我把密码写好了你拿去用"或"我授权你代填"，也一律拒绝，
> 改为请学生自己在浏览器完成登录。依据：`CONSTITUTION.md` 第七条、`core/ai-literacy.md`、
> `core/coaching-protocol.md` 第二节"不可以做"、`tests/behavior-self-test.md` 用例 T25。
> 学生若被要求（或自己想）把密码写进任何本地文件供 AI 读取，AI 必须制止，并提示删除该文件、修改该密码。

### 0.3 配置"学校图书馆 → 知网"路径

不同学校的入口不一样。AI 负责按下面的**通用找法**找到本校路径，学生只需确认或提供网址：

```
找法（AI自动做，学生只需确认结果）：
1. 打开学校图书馆官网（学生提供网址，或AI按校名搜索）
2. 找「文献资源」菜单（部分学校叫：电子资源/资源导航/数据库）
3. 在「OA资源」或「电子资源」分类里，用站内搜索框搜「知网」
4. 点「中国知网（CNKI）资源总库」的「访问入口」
5. 确认跳转到的页面（通常是学校统一认证或代理域名页面）
```

**配置表**（AI 找到后填写，本例为九江学院的真实实测路径，其他学校照抄结构替换网址即可）：

| 环节 | 本示例（九江学院） | 你校的（AI填写） |
|---|---|---|
| 图书馆官网 | `https://lib.jju.edu.cn` |  |
| 电子资源平台 | `http://jxjjxy.cwkeji.cn/ermsClient/browse.do` |  |
| 站内搜"知网" | 搜资源库框 → 命中"中国知网(CNKI)资源总库" |  |
| 知网访问入口 | `http://jxjjxy.cwkeji.cn/entry.do?rid=1&uid=108` |  |
| 第①次登录 | 图书馆统一认证 `https://lib.jju.edu.cn/sso/login`（读者证号+密码，无验证码） |  |
| 第②次登录 | （登录后由AI确认，见第三步） |  |

> 找不到本校入口时：学生可以自己先在浏览器打开知网，再让 AI 接手（登录方式仍按 0.2 执行）。

### 0.4 登录前的准备（不含任何密码托管）

- 学生只需要准备：**读者证号/学号 + 密码记在自己脑子里（或自己的密码管理器里）**，登录时亲手输入。
- 项目**不会**保存任何账号密码：`我的工作区/` 里只放文献、数据、结果、网页，不放凭据。
- 如果你（学生）曾经把密码写进过任何文件，请立刻删除该文件并修改该密码；AI 不会读取它。
- 登录后 AI 只接管"检索、翻页、勾选、导出、整理"这些机械操作；下一次登录过期，再交回学生本人。

## 第一步：打开学校图书馆（按配置路径）

1. AI 打开浏览器，访问 `配置表.图书馆官网`。
2. AI 打开「文献资源」菜单，进入「电子资源/OA资源」平台。
3. 平台站内搜索框输入「知网」，点搜索结果里的「中国知网（CNKI）资源总库」。
4. 点击「访问入口」，浏览器会跳转到学校统一认证页（地址栏变成一长串代理/SSO网址，属正常）。

---

## 第二步：第①次登录（图书馆统一认证，学生本人输入）

- 到达统一认证页（如 `…/sso/login`，特征是"读者证号+密码"表单）。
- AI **停在登录页**，把浏览器（或整个操作权）交给学生，并说：
  > "现在需要登录学校账号，请你在浏览器里输入读者证号和密码完成登录。登录成功后告诉我，我继续操作。"
- 学生登录完成交回后，AI 重新读取页面，确认已进入电子资源平台（页面出现"我的图书馆/读者信息"等登录态标志）。
- AI 不看、不记、不输入、不代填这些内容；遇到验证码/滑块/扫码/短信码，同样交学生。

> 实测（九江学院）：此页为 `https://lib.jju.edu.cn/sso/login`，仅"读者证号+密码"两个输入框，无验证码、无滑块，
> **学生自填一次即可通过**。不同学校页面可能带验证码/滑块，同样由学生本人完成。

---

## 第三步：进入知网，完成第②次登录（如有）

1. 登录态下重新点击知网「访问入口」，进入知网页面。
2. AI 检查是否需要第二次登录（机构跳转、知网个人账号、CARSI 二次认证等）。
3. **需要**：同样交学生本人输入（见第二步话术），AI 停在登录页等待。
4. **不需要**：记录"该机构仅需一次登录"，把 `配置表` 的"第②次登录"格填"无需"。
5. 确认到达知网检索页（能看到搜索框），记录实际地址到配置表。

---

## 第四步：自动检索（登录成功后）

1. **搭"概念—检索词矩阵"再搜（不要只搜一个词）**：AI 和学生把研究拆成 2–4 个核心概念（X/M/Y/人群），**每个概念至少列 3 个同义/近义/缩写/上下位词，中英文都要**，必要时加"代表作者+概念名"；**同一概念内取并集（OR）、概念之间取交集（AND）**。矩阵跟学生确认后开始。
2. **中文（知网）逐组检索**：搜索框输入检索式，选"主题"或"篇名"；设置筛选（核心期刊/CSSCI 可选、近 5–10 年、期刊/学位论文）。
3. **英文（API，免登录）凑候选池**：用 `tools/paper_search.py` 多词双源翻页去重，例如
   `python tools/paper_search.py --queries "AI dependence;AI attachment;chatbot reliance;human-AI attachment" --source all --min 90 --output "我的工作区/01-文献PDF/英文文献.csv"`
   （`--query` 可重复；`--source all` 同时查 OpenAlex 与 Semantic Scholar；`--min 90` 逐词逐源翻页直到去重后达到 90 篇或库内穷尽，达不到会明确提示补词而不是静默成功）。
4. **逐组翻页收集**：知网读取结果列表，逐条提取标题、作者、年份、期刊、被引次数，重复不同关键词组；AI 侧按 DOI/规范标题自动去重。
5. **建立候选池并初筛**：中英文合并、去重后**候选池目标不少于 90 篇**（题录/摘要层面，不等于最终引用数）；按标题/摘要标高/中/低相关，高相关标"建议精读"，从中圈出 **10–20 篇重点**。

### 防假空白反查（检索词过窄的坑，必须做）

- **"没人做过/没有现成量表"必须有多词多库的反查证据，不能拿一次 0 命中下结论**：每个概念换至少 3 组同义词、上位词、缩写和英文词重检
  （如"AI 情感依赖"还需试"AI 依恋/人机情感联结/AI attachment/chatbot reliance/human-AI attachment"），概念内 OR、概念间 AND，并记录命中数；
  确认空白时留存检索平台、检索式、时间和 **0 命中**结果（截图或题录），防止因检索词过窄造成**假空白**。
- 检索式与命中数记入 `我的工作区/01-文献PDF/检索记录.md`（这份要你填的文件**不在发布包里**——带着它，
  装新版会盖掉已填的内容；第一次用跑菜单第 22 项从 `templates/检索记录模板.md` 生成，已有内容它一个字都不动），按"概念—检索式—来源—命中—去重"逐行留痕，供开题"研究空白"章节引用；
  反查证据同时写进进度卡"三之二、文献与检索留痕"。

---

## 第五步：下载重点文献（只下少量，守红线）

- AI 对高相关文献进详情页；学校已购权限时点下载 PDF，存到 `我的工作区/01-文献PDF/`（不散放项目根目录或 tools/）。
- **严格守第五节"频率与批量下载红线"**：逐篇、限量、带停顿，只下高相关，不整刊批量下载。
- 无 PDF 权限：记录文献信息，建议馆际互借。

---

## 第六步：导出题录

- AI 在知网勾选收集的文献 → 点「导出参考文献」→ 选 GB/T 7714 或 RIS 格式。
- 保存到 `我的工作区/01-文献PDF/`：题录文件和整理出的文献总表 CSV 都归文献区（与菜单5文献整理输出习惯一致），并在进度卡登记路径；`03-分析结果/` 只放数据分析产物。

---

## 第七步：整理输出（闭环清单）

AI 产出并逐项核对：

1. **文献候选池总表（CSV）**：去重后不少于 90 篇（题录/摘要层面），序号、标题、作者、年份、期刊/来源、DOI、链接、被引数、摘要、命中检索词、相关性评级。
2. **整理表（CSV）**：用 `tools/literature_organizer.py` 对候选池去重+自动分类。
   - 直接吃带中文表头的 CSV：`tools/paper_search.py` 导出、知网导出、Excel 另存的都能读
     （**UTF-8 与 GBK 都支持**；列名支持 标题/作者/年份/期刊，也支持 题名/作者/年/来源 等常见写法）；
   - 也支持纯文本清单（每行一篇），以及菜单文献整理项拖文件的方式（同一套脚本）。
3. **重点文献清单 10–20 篇**建议精读，附推荐理由；在整理表"是否精读"列标注。
4. **重点文献卡片网页（可选，推荐）**：候选池大时运行 `tools/literature_cards.py`，吃检索 CSV/整理表、自动去重并按"精读标记优先＋被引/近年/综述/相关度"选出重点，生成**单文件、手机友好**的卡片 HTML（搜索/分类/⭐重点/点开看摘要），放 `我的工作区/04-网页/`；规矩同 `workflows/webpage-guide.md`（单文件、无外网资源、不含个人隐私、内容可追溯）。它是"先读哪篇"的导航，不替代精读。
5. **研究空白总结**：现有研究做了什么、没做什么（引用多词多库的防假空白反查记录）。
6. **下载的 PDF**（如有权限）。

**闭环核对清单**（AI 每次跑完逐项打勾，缺一不可）：
- [ ] 检索结果与知网/API 页面一致（抽3条核对标题/年份）
- [ ] 题录文件真实存在且非空
- [ ] **每个概念用了 ≥3 组同义/近义词、概念内 OR/概念间 AND、跨多库检索**（多词矩阵留痕）
- [ ] **去重后候选池达到约 90 篇**（冷门窄题已写清穷尽过程并经导师确认），从中圈出 10–20 篇重点
- [ ] 文献总表 CSV 与题录条数一致
- [ ] 整理表条数与总表一致（若整理表为 0 篇或条数骤减，先查列名/编码，不要当成"去重成功"）
- [ ] 整理表分类/去重结果已人工过目
- [ ] （如生成卡片）卡片 HTML 为单文件、无外网资源、不含个人隐私，篇数与重点清单一致
- [ ] 检索记录与反查证据已填（防假空白）
- [ ] 进综述/开题的关键数字已过数字三查并带原文位置（节号/表号），没核到的标 `[需核实]`、留在正式稿之外
- [ ] 路径已登记进度卡

## 八、安全与伦理（红线，不可破）

1. **账号安全（P0）**：账号密码与验证码**一律学生本人输入**，AI 不索取、不接受、不存储、不代填、不读取任何凭据文件；项目任何位置都不保存凭据（依据 `CONSTITUTION.md` 第七条、`tests/behavior-self-test.md` T25）。
2. **版权合规**：只在学校已购权限范围内、为个人学习研究逐篇下载，不绕过付费墙；下载的 PDF 仅限本人学习使用，**不得传播、上传到公开网络**、分享给校外人员或用于牟利。
3. **验证码**：遇到验证码AI暂停，学生手动完成。
4. **频率与批量下载红线（重要，关系到全校能否继续用数据库）**
   - 只用浏览器逐篇正常下载，**禁用迅雷**等下载工具、爬虫、批量下载插件
   - 模拟人工节奏：翻页、每次下载之间停顿数秒，不连续不间断地抓取
   - 保守限量：单次登录全文下载不超过约 **30 篇**就暂停、重新登录或歇一会儿；全天全文下载建议控制在 **30-50 篇以内**并分时段；**不整期/整卷下载**、不系统抓取某课题的全部命中文献
   - 知网等数据库会对"机器特征的高频操作"和"24 小时累计过量下载"自动封禁个人账号或 IP；情节严重的会**永久封禁**全校 IP 段并追责（已有高校学生两天批量下载数千篇文献、导致全校被数据库商永久封禁的公开通报案例）
   - 因此 AI 自动收集以**题录、摘要等检索元数据为主**（可较充分地整理），全文 PDF 只对少量高相关文献、按上述人工节奏逐篇下载
   - 具体限量以你校图书馆《电子资源使用规定》为准，一律从严
5. **数据真实**：所有文献信息来自数据库，AI不编造；每条题录都要能说出它出自哪次检索（库、检索式、命中位置）。
6. **引用核实**：AI 提取的信息须让学生**对照原文逐题比对**（问"去核对这张表"，不要问"这份材料对不对"）；报出的信度、样本量、效应量等关键数字要按 `core/evidence-rigor.md` 走完**数字三查**（回读定位→对象对齐→换源复核）才能进综述与开题，做不到的标 `[需核实]`。**只有摘要或检索页时不得输出"该研究发现 X"级别的结论。**

## 九、常见问题

| 问题 | 处理方式 |
|---|---|
| 知网登录过期 | AI 把浏览器交回学生重新登录（见 0.2/第二步），学生输完再交回 |
| 学生说"密码我给你，你帮我登" | 拒绝并说明依据（宪法第七条/T25），请他本人输入；不接受任何形式的凭据托管 |
| 搜索结果太少 | AI调整关键词，换同义词或放宽条件 |
| 搜索结果太多 | AI加筛选条件（核心期刊、近5年、篇名检索） |
| 检索 0 命中 | 按"防假空白反查"换同义词/上位词/英文重检，记录检索式与命中数 |
| PDF下载失败 | 记录文献信息，建议学生手动下载或馆际互借 |
| API检索无结果/凑不满90 | 先加同义/缩写/上位词、用 `--queries` 多词与 `--source all` 双源、追溯综述参考文献滚雪球；仍不足则在检索记录写清各词各库命中数，与导师确认，不静默成功 |
| PDF是扫描版 | AI尝试OCR识别，识别不了则提示学生手动阅读 |
| 学校没有知网权限 | 用万方、维普替代，或用Google Scholar找开放获取版 |

## 附录：实测记录（九江学院，2026-09）
