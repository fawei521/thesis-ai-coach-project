## 一、JASP（统计分析软件，强烈推荐）

### 是什么
免费开源的统计软件，界面和SPSS几乎一样，拖拽操作，心理学专业首选。支持信度、相关、回归、中介、因子分析、贝叶斯统计。

### 下载安装（Windows）
1. 打开官网：https://jasp-stats.org/download/
2. 点击 "Windows" 下载安装包（约300MB）
3. 双击下载的 `.exe` 文件
4. 一路点 "Next" / "Install"，使用默认设置
5. 安装完成，桌面出现JASP图标

### Mac
1. 同上官网，点 "Mac OS X" 下载 `.dmg`
2. 打开dmg，把JASP拖到Applications文件夹

### 验证安装成功
- 双击桌面JASP图标，能打开软件，看到欢迎界面
- 点 File → Open，能打开示例数据

### 常见问题
- **Windows提示"无法验证发布者"**：点"更多信息"→"仍要运行"
- **安装慢**：正常，软件较大，耐心等待
- **打开是英文**：菜单 File → Preferences → Interface language选"中文（简体）"→重启

### JASP vs SPSS
- 学校有SPSS：用SPSS即可，AI给的SPSS操作步骤同样适用
- 没有SPSS：用JASP，菜单逻辑几乎一样，结果也能导出
- JASP做中介：最简单用菜单 Regression → Mediation（把自变量、因变量、中介变量拖进去，勾选 Bootstrap、看间接效应的置信区间）；想要 Hayes PROCESS 同款模型，可在 JASP 顶部模块库（"+"按钮）安装官方 PROCESS 模块。SPSS 则需另装 Hayes 的 PROCESS 宏（简单中介 Model 4、链式中介 Model 6）

## 二、Python（运行自动化脚本）

### 是什么
运行本项目 tools/ 目录下脚本的环境（数据清洗、文献检索、自动统计）。

### 下载安装（Windows，关键步骤不能错）
1. 打开官网：https://www.python.org/downloads/
2. 点黄色按钮下载稳定版（建议 3.11 及以上版本即可，不必追刚发布的最新大版本，兼容性更稳）
3. **双击安装包后，最重要的一步**：
   - 安装界面最下方有个勾选框 **"Add python.exe to PATH"（将Python添加到PATH）**
   - **一定要勾选！一定要勾选！一定要勾选！**
4. 勾选后，点 "Install Now"（立即安装）
5. 等待安装完成，点 "Close"

### 验证安装成功
1. 按 `Win + R`，输入 `cmd`，回车，打开黑色命令行窗口
2. 输入：`python --version`，回车
3. 如果显示 `Python 3.11.x` 或类似版本号，说明安装成功
4. 如果显示"不是内部或外部命令"，说明PATH没勾选，重新安装并勾选

### 安装需要的库（可选）
本项目脚本默认只用Python自带功能，不需要额外装库。
如果要用高级图表功能，AI会在需要时告诉你运行：
```
pip install matplotlib
```
AI会在安装前说明这个库是做什么的、多大，征得你同意后再装。

### 怎么运行脚本（AI会帮你，了解即可）
1. 打开脚本所在文件夹
2. 在文件夹地址栏输入 `cmd`，回车
3. 输入AI给你的命令，例如：
   ```
   python tools/auto_stats.py 数据.csv
   ```
4. 或者直接让AI通过虚拟电脑帮你运行

### 常见问题
- **pip下载慢**：AI会教你换国内镜像源
- **权限错误**：不要装在C盘系统保护目录，装在默认目录即可
- **Mac用户**：新版 macOS 已不再预装 Python。打开"终端"输入 `python3 --version` 验证；若提示没有，按弹窗提示安装 Xcode 命令行工具，或从 Python 官网下载 macOS 安装包。Mac 上本项目的命令把 `python` 换成 `python3`、`pip` 换成 `pip3`

## 三、Zotero（文献管理，强烈推荐）

### 是什么
免费开源的文献管理软件，能一键从知网/网页导入文献、管理PDF、自动生成参考文献。

### 下载安装
1. 打开官网：https://www.zotero.org/download/
2. 下载 "Zotero" 桌面版（Windows/Mac/Linux都有）
3. 双击安装，一路默认下一步
4. 建议同时安装浏览器插件 "Zotero Connector"（同一页面，按浏览器类型安装）

### 注册账号（用于同步）
1. 打开 https://www.zotero.org/user/register/
2. 免费注册账号
3. 在Zotero软件：编辑 → 首选项 → 同步，登录账号

### 基本使用
1. **收集文献**：在知网/学术网站打开某篇论文，点浏览器右上角Zotero Connector图标，自动导入
2. **管理PDF**：导入的文献可以拖拽PDF进去，或自动下载
3. **建分类**：左侧"我的文献库"右键→新建分类，如"自变量""因变量""中介"
4. **做标注**：双击打开PDF，可以高亮、加笔记
5. **生成参考文献**：选中文献，右键→由所选条目生成参考文献目录，选GB/T 7714格式

### 中文参考文献格式 GB/T 7714（这是"引用样式"，不是插件）
- 菜单 编辑 → 首选项 → 引用 → 样式，点样式列表下方的 "+"，在样式库搜索 "GB/T 7714"（或"中国国家标准"）添加
- 之后生成参考文献、导出时选择 GB/T 7714 格式即可

### 常用插件（AI可指导安装）
- **Better BibTeX**：和Obsidian联动用
- **PDF Translate**：PDF翻译

### 验证安装成功
- 能打开Zotero，看到"我的文献库"
- 浏览器右上角有Zotero存藏图标
- 打开一篇知网论文，点存藏图标能成功导入

## 四、Obsidian（笔记和写作，可选）

### 是什么
免费的本地笔记软件，用Markdown格式，能和Zotero联动管理文献、写论文、插入引用。数据全在本地，不丢、不上传。

### 下载安装
1. 打开官网：https://obsidian.md/download
2. 下载对应系统版本，安装
3. 打开后点"创建新库（Vault）"
4. 选择一个文件夹作为你的论文资料库（建议在本项目文件夹外单独建，如"我的毕业论文库"）

### 建议的库结构（AI可帮你建）
```
我的毕业论文库/
├── 00-选题/
├── 01-文献笔记/       # 每篇文献一个笔记
├── 02-研究设计/
├── 03-数据与分析/
├── 04-论文草稿/
├── 05-开题答辩/
└── 附件/             # PDF等
```

### 常用插件
- 核心插件（自带，设置里开启）：大纲、关系图谱、标签面板、模板
- 社区插件（设置→第三方插件→浏览）：
  - **Zotero Integration**：从Zotero导入文献笔记
  - **Dataview**：自动汇总文献表
  - **Citation**：插入引用

### 验证安装成功
- 能创建库、新建笔记、输入文字
- 笔记自动保存（不需要手动保存）

### 不想学Obsidian怎么办
完全可以不用。用Word + Zotero也能完成论文。Obsidian是给想建立个人知识库、长期读研的同学准备的。

## 五、安装顺序建议

跟着论文进度走，不要提前装一堆：

1. **选题阶段**：不需要装任何软件
2. **文献检索阶段**：装 Zotero（可选Obsidian）
3. **数据分析阶段**：装 JASP（或用学校SPSS）；想自动化装 Python
4. **写作阶段**：Word或Obsidian任选
