**v1.81 开题 PPT 的中文字体写进主题（换机器不再变字体）**
- **问题**：python-pptx 默认模板的主题里 `a:ea`（东亚字体槽）是空的，中文实际用哪套字体
  全看打开它的那台机器的 Office 主题——自己电脑上是雅黑，拿到学院机房可能变宋体，
  行高字宽一变，12 页开题 PPT 的版式就跟着抖。v1.80 把 PPT 接进菜单时，文档里写的还是
  "字体由各台机器决定、请现场改"，等于把缺陷推给学生。
- **做法**：`pptx_writer` 加 `cn_font` 参数（默认微软雅黑），`save()` 之后重写包内
  `ppt/theme/themeN.xml`，把 major/minor 两组各自的 latin/ea/cs 字体槽统一写死。
  为什么直接改 zip：python-pptx 把主题当不透明二进制部件存着，没有公开 API 能写 `a:ea`。
  重写按原顺序、原压缩方式、原时间戳回填（`[Content_Types].xml` 仍在首位），临时文件同盘替换不留残；
  字体名进 XML 前做 `&<>` 实体转义。`outline_to_ppt.py --cn-font 宋体` 按学校口径换，
  `--cn-font none` 完全不动主题；菜单第 21 项加一问"中文用什么字体"。
- **测试**：+4 条——默认生成后主题两处 `a:ea` 均为微软雅黑；`--cn-font 宋体` 后均为宋体；
  选 `none` 时仍为空（证明"不改"是出路而非静默照改）；改完字体后用 python-pptx 重新打开，
  页数正确且**无形状越出页面边界**（重写 zip 最坏会把包写坏，这条兜住）。full_e2e 643→**647 项全过**。
- 顺带：START 里 v1.80 遗留的"中文字体由各台机器决定"措辞改为"字体已写进主题，换机器仍现场确认版式"；
  README 版本区与 ROADMAP 挂账同步勾结。
- `doubao-skill` 无改动；工具 23、菜单 22 不变。

**v1.78 手机合并单文件构建链路闭环（补丁；doubao-skill 维护者工具改动，规则文字零变化）**
- **现象**：开发树里跑 `tests/full_e2e.py` 有两条红——`Skill自检退出0` 与 `v161旧语气名清零`；
  干净解压副本却是全绿。两条都指向 `doubao-skill/thesis-ai-coach-手机版.md`：
  它是 `.gitignore` 排除的构建产物，停在语气文件改名（gentle-sister/strict-ceo/puppy）之前，
  所以只有开发树会红，报的还是"旧语气名"这种指不到真因的方向。
- **根因是一处路径不一致**：`build_mobile_single.py` 的 `--out` 默认值是裸文件名，按**当前目录**解析。
  从仓库根执行就把 180 KB 产物写进**仓库根**（该路径不在 .gitignore 内，`git add -A` 会把整份重复规则
  误提交），而 `validate.py` 检查的是 `doubao-skill/` 那份 → 重新生成一百次自检也报"不同步"。
  `doubao-skill/README.md` 发布流程第 2 步又写成 `--out <分发包目录>/…`，等于规定了一条
  "只更新分发包副本、永不更新受检副本"的路径，产物必然长期过期。
- **修**：默认输出改为 `ROOT / DEFAULT_NAME`（技能目录内，正是 validate 检查、.gitignore 排除的那份），
  显式 `--out` 的相对路径语义不变；validate 的"不同步"提示改成可执行命令（跑一次生成即可）；
  README 用法与发布流程改为"先在本目录生成、再拷进分发包"；`旧语气名` 断言排除该构建产物
  （产物过期已由 validate 抓，源码断言不该替构建产物报警）。
  **分发包里那份从头到尾是对的**（与重新生成结果字节相同、无旧语气名），本版修的是开发树与工具路径，不是学生拿到的内容。
- **测试**：+2 条行为锁定，真跑子进程断言"生成方与校验方同一路径"这条不变量
  （`v178默认输出落技能目录而非当前目录`、`v178换目录跑--check仍判同步`），测试结束还原产物原状；
  full_e2e 632→**636 项全过**，consistency/validate/py_compile 全绿。Skill v1.4.1（仅维护者工具）。
- **连带修 `consistency_check.py` 两处误报**（都是"防漂移的尺子量错了对象"，与 v1.77 那颗幽灵脚本雷同类）：
