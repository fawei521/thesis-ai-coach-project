# 毕业材料总清单（对照学校要求逐项打勾）

> **为什么要这份**：毕业论文要交的**不只是一篇论文**。任务书、开题、中期检查、指导记录、
> 外文翻译、承诺书、查重报告、答辩记录、各类评审表……多数是**学院发的固定表格**，
> 漏一张通常不是扣分，而是**那次环节不算完成**。本包管内容和质量，**格式以本校文件为准**。
>
> **怎么用**：阶段 0 就跟辅导员/教务**要齐本校这一整套表格**，然后逐行填"我校叫啥名 + 截止日"。
> 状态列 ⬜ 未开始 / 🔄 在写 / ✅ 已交 / ➖ 我校不要求。

---

## 一、先问学校这三件事（只有学生本人拿得到答案）

1. **本校要求交哪几样**——不同学校差很多，别拿别的学校清单当标准。
2. **每样的截止日期**——写进本清单第四列，再同步进进度卡待办。
3. **有没有官方模板/固定表格**——有就直接用学院的版本，本包的模板只帮你把内容想清楚。

拿不到原文的格子一律写 `[需核实]`，**不要按"我见过的学校"来填**。

## 三、「毕业论文计划书」怎么填（本包没有模板，按这个骨架写）

计划书包底的是一件事：**从现在到答辩，什么时候交出什么**。

1. **总时间轴**：开题 → 预试 → 正式施测 → 分析 → 初稿 → 修改 → 定稿 → 查重 → 答辩。
2. **每段填三格**：起止日期 ｜ 这一步的**产出物**（不是"努力做"，是"交出什么文件"）｜ 前置条件。
3. **留缓冲**：收数和按导师意见修改这两段最容易延期，各多留一到两周。
4. **写风险与备案**：样本收不满怎么办、导师换意见怎么办、数据不显著怎么办。
5. **和导师对一遍**：计划书的实质是承诺时间表，导师点头才算定。

## 四、AI 在每个环节的分工

- **提醒有这一张表**：本清单没打勾的，主动报给学生，不说"你自己看着办"。
- **不替他签、不替他编**：承诺书、指导记录、答辩记录必须是真实发生过的记录。
- **不拿别校标准套本校**：格式、页数、重复率、周记次数一律标 `[需核实]` 并让他问教务。
- **学生要 AI 直接出成品时**：走 `core/outcome-delivery.md` 全套，别只交清单里的一件。

## 五、口径来源（供学生查原文，引用前自己核对本校文件）

本清单的"要交哪些"取自三所高校公开发布的规范文件，**三源交叉后取并集**，用于说明这类材料的常见范围，
**不等于你学校的要求**：

- 南京航空航天大学《关于做好毕业设计材料归档工作的通知》：任务书、开题报告、中期检查表、答辩记录表、
  成绩评定表、评阅教师/指导教师/答辩小组用表、诚信承诺书、译文及原文复印件、附录。
- 上海大学社会学院《关于做好 2026 届本科生毕业论文工作的通知》：任务书、开题报告、中期检查材料、
  指导记录（周记）、终稿 PDF、查重报告、附录（文献翻译/问卷/访谈）、承诺书、AI 工具使用说明。
- 江苏海洋大学《本科生毕业实习与设计（论文）管理办法》：选题审题表、任务书、开题报告、
  外文资料译文（附原文）、中期检查表、评语、评分表、答辩记录、诚信承诺书。

**共同点**：三源都要求任务书、开题报告、中期检查、答辩记录、成绩/评分表、诚信承诺书——
这六样是当前 12 阶段流程里没有明确提醒过的，也是最容易漏的。
