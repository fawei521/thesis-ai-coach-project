# 网页范例（4 个现成网页）

> ⚠️ **这四个网页是"范例"，不是模板填空，更不是可以抄袭的素材。**
> 它们来自一位真实学生的毕业论文准备过程。**内容（文献条目、术语释义）请勿直接搬用**——
> 你的文献综述和量表资料必须来自你自己检索、阅读并核实过的文献。
> 可以学的是**做法**（单文件结构、数据组织、交互设计），不是**内容**。

---

## 一、这四个网页分别示范什么

| 范例 | 打开方式 | 示范的做法 | 适合什么时候参考 |
|---|---|---|---|
| [`01-文献笔记网页/index.html`](01-文献笔记网页/index.html) | 双击即可 | 单文件网页＋一个 `DEFAULT_PAPERS` 数组存全部文献；关键词搜索；按分类的 27 个筛选按钮；`localStorage` 记住"⭐重点"；每条带知网检索跳转链接 | 文献检索/阅读阶段，想把手里的文献整理成可检索的页面时 |
| [`02-术语词典网页/index.html`](02-术语词典网页/index.html) | 双击即可（**需联网**才用自定义字体） | 分类 + 卡片布局；`DEFAULT_TERMS` 数组 + `categories`；实时搜索；带 PWA（`service-worker.js` 离线缓存） | 想给自己做一份"读懂论文黑话"的速查页时 |
| [`03-研究流程图/research-flow.html`](03-研究流程图/research-flow.html) | 双击即可 | **纯 HTML/CSS** 画研究流程与变量关系图，不依赖任何图表库；配色与字体用 CSS 变量统一管理 | 开题/答辩要讲清"我的研究怎么做"时 |
| [`04-统计方法选择器/index.html`](04-统计方法选择器/index.html) | 双击即可 | **问答式决策树向导**：数据（NODES 问题节点）与界面（渲染逻辑）分离，按"研究问题→组数/正态/方差"几步选出统计方法，并给出要报告的统计量与效应量、脚本命令、JASP/SPSS 路径和论文句式；底部内置效应量判据速查 | 数据分析前拿不准"我这种数据该用 t、方差分析还是非参数、相关还是回归/中介"时 |

四个都是**双击就能在浏览器里打开**的，不需要装任何东西、不需要服务器。

## 二、给 AI 的具体参考点（读 `workflows/webpage-guide.md` 配合看）

1. **四个页面的共同点，也是本项目推荐的网页做法**
   - **单文件、自包含**：CSS 和 JS 全部内联在 `.html` 里，双击就能用，不会因为少一个文件而白屏。
   - **数据与界面分离**：所有内容放在文件顶部的 JS 数据常量里（`DEFAULT_PAPERS`、`DEFAULT_TERMS`，选择器里是 `NODES`/`RESULTS` 两棵决策树），改数据不用碰界面代码。
   - **零构建**：没有 npm、没有打包、没有依赖，改完刷新浏览器就看到。
   - **中文优先**：字体栈里放 `'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei'`，中文不会出问题。

2. **一处要提醒学生的偏差（教学点）**
   `02-术语词典网页` 和 `03-研究流程图` 用了**一个外链字体**（`miaoda.feishu.cn` 的 CSS）。
   断网或该域名不可用时，会回落到 CSS 变量里写的系统字体（`font-serif` 那一行），**功能不受影响**，只是字形变化。
   **按 `webpage-guide.md` 的规矩，学生自己做时建议不要外链**，直接用系统字体栈即可（少一个外部依赖就少一处会失效的地方）。
   这里保留原样，是为了让学生看到"真实项目里可能出现的不一致"，而不是把它当标准做法。

3. **抄结构的正确姿势**
   - 想看数据怎么组织：打开 `01-文献笔记网页/index.html`，搜索 `DEFAULT_PAPERS`。
   - 想看筛选/搜索怎么实现：搜索 `addEventListener`、`filter(`。
   - 想看不用图表库怎么画关系图：直接读 `03-研究流程图/research-flow.html` 的 HTML 结构与 CSS（**没有 JS**）。

## 三、AI 不要做的事

- ❌ 不要把这四个页面的**内容**（文献题录、术语释义、统计方法结论）直接复制进学生自己的页面或论文——
  题录不是学生自己检索的、无法核实来源；统计方法是否合适取决于学生自己的真实数据与设计。**只能参考代码结构与交互设计。**
- ❌ 不要保留 `service-worker.js` 的 PWA 注册除非学生确实需要离线（本项目默认单文件、`file://` 双击打开即可，
  PWA 的 `service worker` 在 `file://` 协议下本来也不会注册）。
- ✅ 学生要做自己的页面时，用 `workflows/webpage-guide.md` 的流程，产出放在 `我的工作区/04-网页/`。
