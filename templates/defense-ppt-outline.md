# 答辩PPT大纲模板（10-15页）

> 将【】替换为你的内容。每页标注了建议要点和讲稿提示。

---

## 第1页：封面
**内容**：
- 论文题目：【自变量】对【因变量】的影响——【中介1】与【中介2】的链式中介作用
- 答辩人：XXX
- 专业：应用心理学
- 指导教师：XXX
- 答辩日期

**讲稿**：各位老师好，我是XXX，我的论文题目是《……》，指导老师是XXX老师。

---

## 第2页：汇报框架
**内容**：研究背景 → 文献与假设 → 研究方法 → 研究结果 → 讨论与结论（流程图）

**讲稿**：下面我从这五个部分汇报。

---

## 第3页：研究背景
**内容**：
- 现象：【自变量】在【人群】中日益普遍（1个关键数据）
- 问题：与【因变量】等心理行为问题相关（1个关键数据）
- 缺口：内在机制不明
- 配图：数据图或现象示意

**讲稿**：交代"为什么研究这个"，用2个数据说明问题的普遍性和严重性。

---

## 第4页：文献综述与研究空白
**内容**：
- 自变量研究现状（2-3点）
- 因变量影响因素（2-3点）
- 中介变量理论依据
- 研究空白（加粗突出）：基于已检索文献，较少有研究探讨【链式路径】（慎说"国内外首次"，留检索依据）

**讲稿**：快速梳理，重点落在"研究空白"，引出本研究。

---

## 第5页：研究模型与假设
**内容**：
- 研究模型图（X→M1→M2→Y + 直接效应虚线）
- H1-H4假设列表

**讲稿**：基于XX理论，提出链式中介模型和4个假设。这是本研究的核心框架。

---

## 第6页：研究对象与程序
**内容**：
- 样本：N=___，男__人（__%），年龄M±SD
- 取样方式、地区、时间
- 数据收集程序、无效问卷剔除标准（收数前确定：时长/长直线/低变异/高缺失/注意力题）
- **伦理合规**：匿名、知情同意（未成年样本为监护人书面同意＋学生本人同意、学校批准）、敏感题配心理援助资源

**讲稿**：交代数据从哪来、多少、怎么保证质量；若被试是中小学生，主动说明已取得监护人同意和学校批准。

---

## 第7页：研究工具
**内容**（表格）：
| 变量 | 量表 | 题数 | 维度 | α系数 |
|---|---|---|---|---|
| 自变量 | | | | |
| 中介1 | | | | |
| 中介2 | | | | |
| 因变量 | | | | |

**讲稿**：均采用成熟量表，本研究中各量表信度良好（α在.7以上）。

---

## 第8页：数据处理与共同方法偏差
**内容**：
- 分析工具：SPSS + PROCESS模型6，Bootstrap 5000
- 分析流程：信效度→共同方法偏差→描述相关→（人口学差异/卡方，如做）→链式中介
- Harman检验结果：第一因子解释__%（<40%）

**讲稿**：说明用什么方法、为什么用模型6、共同方法偏差不严重。

---

## 第9页：描述统计与相关分析
**内容**：
- 表：各变量均值、标准差、相关矩阵
- 关键结论：变量间相关方向符合预期，为中介检验提供前提

**讲稿**：各变量显著相关，方向与假设一致。

---

## 第10页：链式中介检验结果（重点页）
**内容**：
- 研究模型图，每条路径标注β系数和显著性星号
- 直接效应、间接效应数值

**讲稿**：这是核心结果。X显著预测M1，M1显著预测M2，M2显著预测Y，链式路径成立。

---

## 第11页：中介效应分解（重点页）
**内容**（表格）：
| 效应路径 | 效应值 | Boot SE | 95%CI下限 | 95%CI上限 |
|---|---|---|---|---|
| 直接效应 | | | | |
| X→M1→Y | | | | |
| X→M2→Y | | | | |
| X→M1→M2→Y（链式） | | | | |

**讲稿**：链式中介效应的Bootstrap置信区间为[__,__]，不含0，说明显著。

---

## 第12页：讨论
**内容**：
- 主要发现与已有研究的对照
- 链式路径的理论解释（为什么是这条路径）
- 实践启示（对学校/家长/干预的建议）

**讲稿**：结果支持/部分支持假设，与XX研究一致，说明……；实践上提示……

---

## 第13页：创新点、局限与展望
**内容**：
- 创新点（2-3点）
- 局限：横断设计、方便取样、自我报告
- 展望：纵向设计、多源测量、干预研究

**讲稿**：主动承认局限，体现科学态度。

---

## 第14页：结论
**内容**：3-4条核心结论（每条一句话）
1. 【自变量】显著预测【因变量】；
2. 【中介1】【中介2】分别起中介作用；
3. 【中介1→中介2】起链式中介作用。

**讲稿**：用最简洁的话总结研究发现。

---

## 第15页：致谢
**内容**：感谢指导教师、参与问卷的同学、答辩老师
- "恳请各位老师批评指正！"

**讲稿**：感谢XXX老师的悉心指导，感谢所有参与问卷的同学，谢谢各位老师，请老师们提问。

---

## 制作提醒
- 每页正文不超过6行，字号不小于20
- 数字、模型图、三线表务必与论文完全一致
- 不用花哨动画，简单切换即可
- 提前在答辩教室电脑测试（字体、公式、图片是否错位）
- 导出一份PDF备用
