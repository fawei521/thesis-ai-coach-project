# coach-rules 分片 · 12 阶段工作流细则

> 摘自 `core/coach-rules.md`：本节自 v1.84 起**从每次对话必读的主手册下沉为按需读**，正文一字未改。
> 每轮都要在场的规则本体（角色、核心原则、语气风格、难度、进度卡、学术红线、紧急模式、检查闸）仍留在 `core/coach-rules.md`。

---

> 每个阶段标注了对应的工作流手册（workflows/），进入阶段时先读取对应文件按其执行。

### 阶段0：项目初始化与环境准备
- 了解学生基本情况（专业、题目、做到哪了）与三项偏好：语气风格（默认自然、不套人设；可选简洁直接/温和耐心/活泼热情）、难度基础、鼓励档（默认"标准"：结合状态与难度自然给具体肯定；可选"精简/关闭"，以后随时说"关闭鼓励/开启鼓励"切换）
- **先要齐本校那套表格**：毕业论文要交的不止一篇论文——任务书、计划书、开题报告与PPT、中期检查表、指导记录、外文翻译、诚信承诺书、查重与AI检测报告、答辩记录表、成绩评定表，多数是学院发的固定表格，只有学生本人拿得到。带他逐项填 `我的工作区/我的毕业材料清单.md`（缺了跑菜单第22项生成），截止日期同步进进度卡；学校没要求的格子如实标 ➖，**别拿别的学校的清单当标准**
- 向学生介绍已预置的 `我的工作区/`（01-文献PDF、02-问卷数据、03-分析结果…九个目录），后续个人文件统一放这里
- **进度卡先确认在不在**：包里只带空白基线 `templates/progress-template.md`，`我的工作区/我的论文进度.md`
  缺失时跑菜单第22项（`python tools/setup_workspace.py`）生成，再带学生填写基本信息和选题部分；
  卡已存在就直接接着用——工具和你都不许覆盖学生已填的内容
- 需要软件时读取 `workflows/environment-setup.md`，指导安装JASP/Zotero/Python/Obsidian
- 可开虚拟电脑帮学生安装，但密码/授权由学生自己操作
- 告诉学生：不想记命令可双击根目录「启动工具箱.bat」用图形菜单；没数据时可用菜单第7项生成演示数据练手
- 完成标志：学生认识工作区、进度卡已开始填写、所需软件就绪

### 阶段1：选题探索
- 了解学生兴趣方向
- 给3个具体选题方向（含变量、模型、困难）
- 学生选一个后，搭"概念—检索词矩阵"：每个核心概念至少 3 个同义/近义/缩写词（中英文），概念内 OR、概念间 AND（见阶段2）
- 可用 paper_search.py 快速检索英文文献验证创新性
- 提醒学生自己去数据库验证，不凭AI判断"没人做过"
- 完成标志：选题确定，核心变量确定，初步确认无完全重复研究

### 阶段2：文献检索（自动化）
- 读取 `workflows/literature-auto-search.md` 执行（该工作流为**可选功能**，先由学生本人决定是否启用；不启用则只用英文 API + 学生自己检索）
- 中文：开虚拟电脑走学校图书馆→知网路径；**登录一律由学生本人在浏览器完成**（AI 不索取、不代填、不保存密码，也不读取任何凭据文件），AI 只做自动检索/翻页/收集题录/限量下载
- 英文：运行 paper_search.py（OpenAlex/Semantic Scholar 免费 API）。**每个核心概念至少准备 3 个同义/近义/缩写词**（如 AI 依赖：AI dependence / AI attachment / chatbot reliance / human-AI attachment），用可重复 `--query` 或 `--queries` 一次传入、`--source all` 双源、`--min 90` 逐词逐源翻页，按 DOI/规范标题去重，凑出**至少 90 篇候选池**；概念内取并集（OR）、概念间取交集（AND）
- 用 literature_organizer.py 去重、分类、标重点（可直接吃 paper_search 导出的标准 CSV）
- 检索式与命中数记入 `我的工作区/01-文献PDF/检索记录.md`；**单次 0 命中不等于"没人做过"**，须换同义词/上位词/英文词反查留证（防假空白）后再下结论；**任何"这个题目没人做过/没有现成量表"的判断，都必须在多组近义词、多个库交叉检索之后才能下**
- 总结研究空白
- 完成标志：**去重后至少 90 篇候选文献**（题录/摘要层面的候选池，不等于最终引用数）收集、分类整理，从中筛出 **10–20 篇重点**标出，检索记录（概念—检索式—来源—命中—去重）留痕齐全；候选池宁大勿小，避免漏掉关键文献

### 阶段3：文献整理与精读（自动化）
- 读取 `workflows/paper-reading-guide.md` 执行
- 学生上传PDF后，AI按IMRaD框架逐篇结构化提取
- 生成文献对比矩阵和研究空白分析
- 可选：配置Zotero+Obsidian（`workflows/toolchain-guide.md`）
- 可选：文献量大（几十篇以上）且学生反复检索困难时，按 `workflows/webpage-guide.md` 带他做一个**文献笔记网页**（放 `我的工作区/04-网页/`）；内容必须来自学生自己检索并读过的文献
- 可选：候选池建好后，运行 literature_cards.py 把重点文献自动生成**手机友好的重点文献卡片网页**（从检索 CSV/整理表读、去重、按重点/被引/相关度筛选），方便学生在手机上挑重点精读；它是"读什么"的导航，不是精读替身，规矩同 `workflows/webpage-guide.md`（单文件、无外网资源、不含个人隐私、内容可追溯）
- 重点文献学生必须亲自精读，AI提取是地图不是替身；AI 报出的每个关键数字都要带"逐字原文＋节号/表号＋读的是全文还是摘要"，规则见 `core/evidence-rigor.md`
- 完成标志：文献表/笔记做好，研究空白明确，综述素材齐备

### 阶段4：量表选择
- 参考 psychology/scale-library.md，对每个变量推荐3个量表
- **多词交叉核验，禁止单词下结论**：对每个变量，至少用 3 组同义/近义词、中英文、常见缩写、以及"代表作者+概念名"分别检索（如孤独感：loneliness / lonesomeness / social isolation / UCLA Loneliness Scale / Russell 孤独），概念内 OR、概念间 AND；**只有多组词、多个库（知网/万方/Google Scholar/原文手册）都查不到，才能判断"没有现成量表、需要自编"**，并把各组检索式与命中数留痕
- 列题数、维度、信度、验证样本、出处，做对比表给推荐
- 提醒学生找到原文核实题目和计分，量表信息不允许编造
- 完成标志：每个变量量表确定（已用多组近义词交叉核验），对比表做好，已跟老师确认

### 阶段5：问卷设计
- 用 templates/questionnaire-template.md 整合完整问卷
- 知情同意、指导语、人口学、量表、结束语
- 算总题数和填写时间（控制60-80题）
- 检查引导性题目、反向计分、敏感题风险提示
- **数据质量埋点（后期清洗依赖，发布前必做）**：保留问卷星自动记录的"作答时长"列；在量表中后段放 1–2 道注意力检查题（模板第六部分，不计入量表总分）；开启同设备限填一次
- **多选题/开放填空题与量表分开**：多选题（"以下哪些…"）和开放填空只用于描述统计，不计入任何量表总分与信度；在问卷星里与量表单选分区清晰，导出后预处理会单列、清洗器自动排除其 0/1 哑变量，写 scales.txt 时勿列入
- 未成年人样本加监护人同意（见 psychology/ethics.md）
- 完成标志：完整问卷做好，预测试完成（如有时间）

### 阶段6：研究方法确定与开题
- 读取 `workflows/proposal-guide.md`，用 templates/proposal-template.md 写开题报告
- 推荐分析方法，每个方法给操作步骤和结果解读
- **用 sample_size.py（菜单第8项）按效应量/α=.05/功效=.8 估算最小样本量**，叠加无效卷冗余与中介下限（简单中介≥200、链式≥300），回答"要发多少份"，并提示用 G*Power 复核截图
- 准备开题PPT和高频问答，模拟开题
- 讨论补充分析（如网络分析）的适用性
- 完成标志：开题报告完成、开题通过、分析计划确定

### 阶段7：数据收集
- 设计发放话术（微信群/朋友圈/请老师转发）
- 规划发放渠道
- 问卷星导出后运行 wjx_preprocess.py 预处理，再运行 data_cleaner.py 按五指标清洗（作答时长过短、长直线、个体内低变异SD、作答题高缺失、注意力检查题答错），导出清洗后数据与"_清洗报告.csv"剔除明细；剔除标准在收数前定好，严禁为凑显著而删数据
- 反向计分、量表总分由 auto_stats.py 依据 scales.txt 自动完成（务必先和学生核对哪些是反向题）
- 样本量不够时想办法，绝不允许编数据
- 完成标志：有效样本达到目标，数据清洗完毕

### 阶段8：数据分析与可视化（自动化）
- 读取 `workflows/data-analysis-auto.md` 执行
- 自动部分：写好 scales.txt（含反向题(R)标记），运行 auto_stats.py 一条命令完成
  人口学频数表、反向计分、信度（Cronbach α＋逐题CITC/删题α＋分半信度Spearman-Brown/Guttman λ4）、结构效度（各量表KMO/Bartlett/因子载荷，自编量表加 `--efa` 做完整探索性因子分析＋平行分析＋碎石图）、共同方法偏差Harman、量表总分、描述统计（偏度/峰度正态性）、相关（Pearson/`--spearman`/`--partial`，自动出相关热图）、人口学差异（参数 t/ANOVA 或 `--nonparametric` 非参数）、人口学交叉卡方、回归＋VIF，导出三线表、量表总分数据集与各专题表/图
- 中介：加 `--mediators`（1个=模型4，2个=模型6链式）自动出Bootstrap间接效应和95%CI；
  再引导学生用JASP/SPSS打开"_量表总分.csv"做PROCESS复核（正式结果以JASP/SPSS为准）
- 每步检查学生的结果并解释，不显著如实处理
- 运行 chart_generator.py 生成研究模型图
- 可选：结果表/图较多、学生看不清整体时，按 `workflows/webpage-guide.md` 带他做一个**数据分析结果看板**，把 `我的工作区/03-分析结果/` 里的三线表、相关热图、中介结果整理成一页；数字必须来自学生自己跑出的结果
- 完成标志：所有分析完成，结果能解释，三线表、中介效应表和模型图做好

### 阶段9：论文写作
- 读取 `workflows/writing-guide.md` 执行
- 用 templates/paper-outline.md 列详细大纲
- 建议顺序：方法→结果→综述→引言→讨论→结论→摘要
- 一章一章带：学生自己写→你帮改语言、查逻辑、补文献
- 正文以学生自己写为主；学生明确要求时，你可按其真实材料起草可编辑段落，但必须标注"AI 草稿"、逐段报告风险，经其逐句核实、用自己的话改写；去AI味、查引用真实性
- 最终检查：格式、引用、错别字、查重、AI检测、AI使用声明
- 完成标志：论文初稿完成，修改2轮以上，格式检查通过

### 阶段10：跟老师沟通
- 读取 `workflows/communication-guide.md`，按其中的原则、节奏和分场景话术引导学生
- 见老师前：准备材料清单，模拟老师提问，把要问的问题整理成"选择题"
- 核心原则：带方案去，给老师做选择题；定期汇报不失联；对事不对人
- 见老师后：帮学生客观分析老师反馈（区分方向性否定/细节修改），复述确认后落实下一步
- 每次沟通后把老师意见记入进度卡"关键决策日志"
- 完成标志：每次沟通后有反馈记录和行动计划

### 阶段11：答辩准备
- 读取 `workflows/defense-guide.md`，用 templates/defense-ppt-outline.md
- 做10-15页PPT（字少图多），写5-10分钟发言稿
- 用24个高频问题库准备，你扮演多位评委模拟答辩
- 完成标志：PPT做好、问答准备好、模拟答辩至少1轮
